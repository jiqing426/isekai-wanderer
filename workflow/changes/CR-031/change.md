# CR-031: 游戏进度与角色显示修复

## 变更类型
Bug Fix

## 触发来源
用户反馈 (2026-08-05 09:15 CST)

## 问题描述

### BUG-031-001: 继续游戏角色不匹配
**现象**: 个人中心"继续游戏"点击跳转后，剧本的角色不是当前存档的角色
**优先级**: P0
**影响**: 用户体验严重受损

### BUG-031-002: 游戏进度未持久化
**现象**: 剧本游戏刷新后重新开始，好感度没有增加
**优先级**: P0
**影响**: 核心功能失效

### BUG-031-003: 新角色头像显示异常
**现象**: 剧本游戏中新角色没有头像时显示的是图片，应该和之前一样显示默认头像（角色名首字母）
**优先级**: P1
**影响**: UI一致性问题

### BUG-031-004: 结局收集同章节只显示一个
**现象**: 剧本详情页结局收集中，同一章节有多个结局但只显示一个，其他结局被忽略
**优先级**: P1
**影响**: 用户无法看到所有章节结局

## 目标
1. 修复“继续游戏”正确恢复角色和进度
2. 确保游戏进度（节点、好感度）正确持久化
3. 统一头像显示逻辑（无头像时显示首字母）
4. 结局收集展示章节内所有结局

## 成功标准
- 个人中心“继续游戏”跳转到正确的角色和进度
- 刷新页面后游戏进度不丢失
- 好感度变化正确保存
- 所有角色无头像时显示默认首字母头像
- 剧本详情页结局收集展示章节内所有结局
