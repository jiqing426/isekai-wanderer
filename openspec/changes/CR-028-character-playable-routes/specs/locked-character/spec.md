# Spec: 锁定角色展示

### Requirement: 未解锁角色显示锁定状态

#### Scenario: 锁定角色视觉展示
- **Given** 角色 unlock_type='paid' 且用户未解锁
- **When** 用户在剧本详情页查看该角色
- **Then** 角色卡片显示锁定遮罩（半透明灰色覆盖）
- **And** 显示锁定图标 🔒
- **And** 不显示「🎮可玩」标识
- **And** 显示解锁价格标签

#### Scenario: 锁定角色点击交互
- **Given** 角色处于锁定状态
- **When** 玩家点击该角色卡片
- **Then** 弹出解锁提示弹窗
- **And** 弹窗内容："该角色需付费解锁（{unlock_price}碎片）"
- **And** 弹窗包含"确定"按钮关闭弹窗
- **And** 不触发角色选中
- **And** 不触发开始游戏

#### Scenario: 用户解锁后角色状态更新
- **Given** 用户已解锁某付费角色
- **When** 用户再次进入剧本详情页
- **Then** 该角色不再显示锁定遮罩
- **And** 显示「🎮可玩」标识
- **And** 可正常点击选中
