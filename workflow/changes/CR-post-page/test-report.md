## 4. 缺陷清单

### BUG-001: 点赞功能未实现
- **严重程度**: P1 - 高
- **影响范围**: 所有用户
- **复现步骤**:
  1. 登录系统
  2. 进入帖子详情页
  3. 点击点赞按钮
  4. 请求返回 404
- **期望结果**: 点赞成功，点赞数+1
- **实际结果**: 404 Not Found
- **根因**: 后端未实现 POST /api/v1/ugc/posts/{id}/like 端点

### BUG-002: 删除评论功能未实现
- **严重程度**: P2 - 中
- **影响范围**: 已登录用户
- **复现步骤**:
  1. 登录系统
  2. 发表评论
  3. 尝试删除自己的评论
  4. 请求返回 404
- **期望结果**: 删除成功，评论数-1
- **实际结果**: 404 Not Found
- **根因**: 后端未实现 DELETE /api/v1/ugc/posts/{id}/comments/{comment_id} 端点

### BUG-003: 浏览量字段缺失
- **严重程度**: P3 - 低
- **影响范围**: 所有用户
- **复现步骤**:
  1. 获取帖子列表或详情
  2. 检查响应字段
- **期望结果**: 包含 view_count 字段
- **实际结果**: 响应中不包含 view_count 字段
- **根因**: API响应结构未包含浏览量字段
