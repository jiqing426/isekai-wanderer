# BUG-029-001: 剧本游戏中负好感度选项不可见

## 问题描述

用户反馈：剧本游戏中选择为什么没有减好感度的，全都是加好感度。

## 数据分析

数据库统计：
- 加好感度选项：98 个
- 减好感度选项：25 个
- 中性选项：2 个

**结论**：负好感度选项存在（25个），但玩家在游戏中看不到或走不到。

## 可能原因

1. **节点路径问题**：负好感度选项所在的节点不在玩家的主要游戏路径上
2. **选项文案问题**：负好感度选项的文案不够明显，玩家不敢选
3. **节点过滤问题**：CR-029 的 `character_id` 过滤逻辑可能误过滤了某些节点
4. **数据填充问题**：MVP 剧本的分支节点可能没有正确配置负好感度选项

## 排查步骤

### BE 排查

1. **检查节点路径**
   ```sql
   -- 找出负好感度选项所在的节点
   SELECT n.id, n.text, n.character_id, nc.text, nc.affection_delta
   FROM nodes n
   JOIN node_choices nc ON nc.node_id = n.id
   WHERE nc.affection_delta < 0
   ORDER BY n.id;
   ```

2. **检查这些节点是否被 CR-029 过滤**
   ```sql
   -- 检查负好感度节点的 character_id
   SELECT n.id, n.character_id, COUNT(nc.id) as negative_choices
   FROM nodes n
   JOIN node_choices nc ON nc.node_id = n.id
   WHERE nc.affection_delta < 0
   GROUP BY n.id, n.character_id;
   ```

3. **检查 NarrativeEngine 过滤逻辑**
   - 文件：`backend/app/services/narrative/script_service.py`
   - 方法：`get_node_with_choices()`
   - 检查 `session_character_id` 过滤是否误过滤了公共节点

4. **检查 MVP 剧本数据**
   - 文件：`backend/scripts/data/cr029_star_moon_branch_nodes.sql`
   - 检查分支节点是否包含负好感度选项

### FE 排查

1. **检查选项渲染逻辑**
   - 文件：`frontend/src/views/GameView.vue`
   - 检查是否正确渲染所有选项（包括负好感度）

2. **检查选项样式**
   - 负好感度选项是否有特殊样式（如红色）
   - 是否被隐藏或禁用

## 预期修复

1. 如果是数据问题：补充负好感度选项到主要游戏路径
2. 如果是过滤问题：修复 NarrativeEngine 过滤逻辑
3. 如果是前端问题：修复选项渲染逻辑
