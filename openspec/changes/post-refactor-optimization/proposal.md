# CR-008 Proposal — 重构后页面优化

## 背景

重构后页面存在多个问题需要优化：
1. 后端接口缺失或报错（500、404）
2. 用户中心功能不完善
3. 设置页面需要优化
4. 碎片中心功能缺失

## 目标

- 修复所有后端接口问题
- 完善用户中心功能
- 优化设置页面体验
- 实现碎片中心功能

## 范围

### 后端（29 个接口）
- 第一批 18 个接口：用户中心 + 个人中心
- 第二批 8 个接口：设置页面优化
- 第三批 3 个接口：碎片中心

### 前端
- 个人中心页面（9 个模块卡片）
- 设置页面优化（左右分栏、5 个模块）
- 碎片中心页面（3 个 Tab）
- 其他页面优化（登录/注册、DiscoverView、Header、引导页面）

## 约束

- 采用 CEO 直连模式，跳过完整 OpenSpec 流程
- 由 CEO 直接确认任务清单
- 由 PL 编写 API Contract 替代设计文档

## 风险

- 数据库表手动创建，未走 Alembic 迁移
- 部分接口依赖现有数据结构，可能需要调整
- 前端页面重构可能影响现有功能

## 验收标准

- 所有 29 个后端接口通过测试
- 前端页面功能正常
- 无 P0/P1 缺陷
- 安全审查通过
