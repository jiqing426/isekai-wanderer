# CR-022: 角色聊天界面用户反馈修复

## 变更概述

**变更类型**: Bug Fix + Feature Completion  
**优先级**: P0  
**创建时间**: 2026-07-29T10:30:00+08:00  
**来源**: 用户验收测试反馈（2026-07-29 09:53）

## 问题描述

用户在验收测试中发现以下问题：

### 问题1: 角色数据不对（P0）
- **现象**: 左侧角色列表显示的好感度数据与实际不符
- **根因**: `CharacterChatView.vue` 只调用了 `characterApi.getCharacters()`，该 API 不返回好感度数据
- **影响**: 好感度进度条和数值都是错误的

### 问题2: 缺少跳转详情按钮（P0）
- **现象**: 右侧聊天界面右上角缺少跳转角色详情页的按钮
- **根因**: `ChatWindow.vue` 的 `chat-header` 只实现了角色名称和好感度显示，未实现跳转功能
- **影响**: 用户无法从聊天页面快速跳转到角色详情页

## 修复方案

### TASK-FE-001: 修复角色列表好感度数据
**负责人**: FE  
**预估时间**: 1-2小时  

**实现方案**:
1. 在 `CharacterChatView.vue` 中同时调用 `characterApi.getCharacters()` 和 `affectionApi.getAffections()`
2. 将好感度数据合并到角色列表中
3. 更新 `CharacterList.vue` 正确显示合并后的数据

**验收标准**:
- AC-FE-001: 左侧角色列表正确显示每个角色的好感度进度条和数值
- AC-FE-002: 好感度数据与 `/api/v1/affection` 返回的数据一致

### TASK-FE-002: 添加角色详情跳转按钮
**负责人**: FE  
**预估时间**: 0.5-1小时  

**实现方案**:
1. 在 `ChatWindow.vue` 的 `chat-header` 中添加"查看详情"按钮
2. 点击按钮跳转到 `/characters/{characterId}`

**验收标准**:
- AC-FE-003: 聊天窗口右上角显示"查看详情"按钮
- AC-FE-004: 点击按钮跳转到对应角色的详情页
