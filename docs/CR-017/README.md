# CR-017 解锁动效系统

## 功能范围

新增全局解锁弹窗组件 UnlockModal，用于展示 CG/成就/隐藏剧情/角色语音/限定剧本等解锁动画，强化成就感。

## 核心功能

### 1. 解锁类型支持

| 类型 | 显示方式 | 稀有度支持 | 动画效果 |
|------|----------|------------|----------|
| CG 解锁 | 卡片 | ✅ R/SR/SSR | card_bounce_in |
| 成就解锁 | 徽章 | ❌ | badge_rotate_in |
| 隐藏剧情 | 卡片 | ❌ | card_bounce_in |
| 角色语音 | 卡片 | ❌ | card_bounce_in |
| 限定剧本 | 卡片 | ✅ R/SR/SSR | card_bounce_in |
| 奖励飘字 | 浮动文本 | ❌ | float_up_fade |
| 奖励汇总 | 汇总面板 | ❌ | scale_in |

### 2. 稀有度视觉系统

- **R (普通)**: 蓝色边框 + 粒子效果 (glow: 0.5)
- **SR (稀有)**: 紫色边框 + 粒子效果 (glow: 0.7)
- **SSR (传说)**: 金色边框 + 粒子效果 (glow: 1.0)

### 3. 动画时序

- 背景变暗: 200ms
- 卡片弹入: 400ms
- 图标出现: 500ms
- 文字淡入: 600ms
- 按钮延迟: 800ms
- 关闭动画: 300ms

### 4. 交互规则

- 弹窗居中显示
- 点击遮罩可关闭
- ESC 键可关闭
- 按钮点击关闭
- 支持跳过动画
- 同时只显示一个弹窗
- 支持批量奖励汇总

## 配置文件

- `unlock_config.json` — 解锁类型、动画时序、交互规则、稀有度视觉配置
- `unlock_copy.json` — 解锁事件文案模板
