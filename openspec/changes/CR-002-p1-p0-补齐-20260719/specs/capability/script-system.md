# S-CR2-001 路线图探索（CR-002 补充）

**MAS（最小可用标准）**：剧本完成后查看已探索/未探索分支，高亮/灰色区分。

## REQ-CR2-001: 路线图探索

### Requirement: 路线探索展示

**ID**: REQ-CR2-001-R01
**优先级**: P1

剧本完成后，用户在剧本详情页点击路线探索可查看路线图，已探索分支高亮，未探索灰色。

#### Scenario: 玩家查看路线探索图

- **Given** 玩家已完成某路线的好结局
- **When** 玩家在剧本详情页点击"路线探索"
- **Then** 系统展示路线图，已探索分支高亮，未探索分支灰色并显示解锁条件提示

#### Scenario: 玩家未完成任何结局

- **Given** 玩家未完成任何结局
- **When** 玩家进入剧本详情页
- **Then** 路线探索入口显示"完成剧本后解锁"
