# BUG-029-012: AI记忆显示角色UUID而非名称

**优先级**: P1  
**发现时间**: 2026-08-04 10:25  
**报告人**: PL  

## 问题描述

个人中心 AI 记忆页面中，角色显示为 UUID（如 `900a9744-04ca-4c6b-a276-c795952`）而非角色名称（如"沈星澜"）。

## 数据库验证

```sql
SELECT id, name FROM characters WHERE id = '900a9744-04ca-4c6b-a276-c79595218672';
-- 结果: 沈星澜
```

## 可能原因

### 1. 后端 API 返回数据问题

`backend/app/api/v1/memories.py` 第 145 行：
```python
"character_id": str(m.character_id) if m.character_id else None,
```

只返回了 `character_id`，没有返回 `character_name`。

### 2. 前端显示逻辑问题

`PersonalCenterView.vue` 第 363 行：
```vue
<div class="memory-character">{{ memory.character_name }}</div>
```

前端期望 `character_name` 字段，但后端没有返回。

## 排查方向

### BE 排查

1. **检查记忆列表 API 返回字段**：
   ```python
   # memories.py list_memories()
   return {
       "memories": [
           {
               "id": str(m.id),
               "character_id": str(m.character_id),
               "character_name": ???,  # 缺少这个字段
               "content": m.content,
               ...
           }
       ]
   }
   ```

2. **修复方案**：
   - 查询 Character 表获取角色名称
   - 或者在 CharacterMemory 模型中添加 character_name 字段（冗余存储）

### FE 排查

1. **检查前端是否有 character_name 映射逻辑**：
   - 如果没有，需要从 characterStore 获取
   - 或者后端必须返回 character_name

## 修复方案

### 方案 A: 后端返回 character_name（推荐）

修改 `backend/app/api/v1/memories.py`：

```python
async def list_memories(...):
    # 查询记忆
    memories = await db.execute(stmt)
    
    # 批量查询角色名称
    character_ids = [m.character_id for m in memories if m.character_id]
    characters = await db.execute(
        select(Character).where(Character.id.in_(character_ids))
    )
    char_map = {c.id: c.name for c in characters}
    
    return {
        "memories": [
            {
                "id": str(m.id),
                "character_id": str(m.character_id),
                "character_name": char_map.get(m.character_id, "未知角色"),
                "content": m.content,
                ...
            }
            for m in memories
        ]
    }
```

### 方案 B: 前端映射（不推荐）

修改 `PersonalCenterView.vue`：
- 从 characterStore 获取角色名称
- 需要确保 characterStore 已加载所有角色
