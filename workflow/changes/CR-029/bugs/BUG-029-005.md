# BUG-029-005: 章节进度条百分比计算错误

**优先级**: P1  
**发现时间**: 2026-08-04 09:18  
**报告人**: PL  

## 问题描述

剧本游戏上面的章节进度条应该根据对话轮数来计算百分比，现在的百分比完全不对。

## 预期行为

进度百分比 = 当前对话轮数 / 总对话轮数 × 100%

例如：
- 总共 10 轮对话
- 当前第 3 轮
- 进度 = 30%

## 实际行为

百分比计算错误，与实际进度不符。

## 可能原因

1. **FE 进度计算问题**: 使用了错误的分子或分母
2. **节点计数问题**: 可能按节点数而非对话轮数计算
3. **总轮数获取问题**: 未正确获取剧本的总对话轮数
4. **当前轮数问题**: 未正确计算当前已进行的对话轮数

## 排查方向

### FE 排查
- 文件: `frontend/src/components/ChapterProgress.vue` 或 `frontend/src/views/GameView.vue`
- 检查进度百分比的计算公式
- 检查当前轮数和总轮数的获取逻辑
- 检查进度条渲染逻辑

### BE 验证
- 文件: `backend/app/api/v1/game.py`
- 检查 `/game/{session_id}/status` API 是否返回正确的进度信息
- 检查是否提供 `current_turn` 和 `total_turns` 字段

## 修复方案

1. **确认进度计算逻辑**:
   ```javascript
   // 正确公式
   const progress = (currentTurn / totalTurns) * 100;
   ```

2. **确保数据源正确**:
   - `currentTurn`: 从 `game_sessions.choice_history` 长度计算
   - `totalTurns`: 从剧本节点路径计算（需要 BE 提供）

3. **如果 BE 未提供总轮数**:
   - 修改 BE API 返回 `total_turns`
   - 或 FE 根据节点深度估算
