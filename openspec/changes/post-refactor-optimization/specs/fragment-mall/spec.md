# Fragment Mall Spec — CR-008 V3

## 需求概述

修复碎片商城相关缺陷，优化 Tab 切换体验，展示已有图片。

## 需求列表

### REQ-BUG-013: 收支明细数据修复（P1）

**场景 1**: 获取收支明细
- 碎片商城页面显示"收支明细"Tab
- 调用 `GET /users/me/transactions` 返回 200
- 响应包含 `transactions: Transaction[]` 数组
- 每条记录包含：类型（收入/支出）、数量、时间、描述

**场景 2**: 明细为空
- 接口返回 `transactions: []`
- 前端显示"暂无收支记录"

**场景 3**: 分页加载
- 支持分页参数 `page` 和 `size`
- 默认每页 20 条
- 滚动到底部自动加载下一页

**验收标准**:
- AC-013-1: 调用 `GET /users/me/transactions` 返回 200
- AC-013-2: 响应包含 `transactions: Transaction[]` 数组
- AC-013-3: 前端收支明细列表正常显示
- AC-013-4: 支持分页加载

### REQ-FEAT-028: 碎片商城 Tab 优化（P2）

**场景 1**: Tab 位置调整
- 碎片商城 Tab 从底部移到页面顶部
- Tab 固定在页面顶部（sticky）
- 滚动时 Tab 保持可见

**场景 2**: 切换刷新数据
- 切换 Tab 时自动刷新当前 Tab 数据
- 显示加载指示器
- 数据加载完成后更新列表

**场景 3**: Tab 状态保持
- 切换 Tab 后返回列表，Tab 位置保持不变
- 不重置到第一个 Tab

**验收标准**:
- AC-028-1: Tab 切换到页面顶部
- AC-028-2: 切换 Tab 时刷新数据
- AC-028-3: Tab 位置固定（sticky）

### REQ-FEAT-029: 商城图片展示（P2）

**场景 1**: 展示商品图片
- 商品列表展示商品图片
- 图片来源：`goods[].image_url`（数据库已有字段）
- 无需爬取，直接展示后端返回的 URL

**场景 2**: 图片缺失
- `image_url` 为空时显示默认商品占位图
- 不显示破损图片图标

**场景 3**: 图片加载失败
- URL 无效或网络错误时显示占位图
- 使用 `onerror` 处理 fallback

**验收标准**:
- AC-029-1: 商品列表展示 `image_url` 字段图片
- AC-029-2: 无图片时显示默认占位图
- AC-029-3: 图片加载失败时显示占位图

## 依赖

- BE: 需要实现 `GET /users/me/transactions` 接口
- BE: 需要确保商品接口返回 `image_url` 字段

## 风险

- 收支明细数据量大时性能问题，需要分页优化
