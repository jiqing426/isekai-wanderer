# BUG-029-006: 个人中心每日任务布局和交互问题

**优先级**: P2  
**发现时间**: 2026-08-04 09:18  
**报告人**: PL  

## 问题描述

个人中心页面中每日任务存在多个问题：

1. **任务触发条件错误**: "对话达人"任务应该是自由对话、角色聊天触发，不是选择对话
2. **刷新时间位置**: 每日 0:00 刷新时间应该放到中间，现在右侧
3. **奖励按钮布局**: "奖励 5 个碎片"按钮应该在任务描述右侧，现在可能在其他位置
4. **按钮状态问题**: 按钮默认置灰不能点击，任务达到后显示蓝色可以点击领取
5. **按钮出现时机**: 不要放到下面等任务完成后才出现，应该一开始就显示（置灰状态）

## 预期行为

### 布局
```
┌─────────────────────────────────────────┐
│ 对话达人              0:00 刷新         │
│ 完成 3 次自由对话      奖励 +5 碎片     │
│ [=====>      ] 2/3     [领取] (置灰)    │
└─────────────────────────────────────────┘
```

### 交互
- **未完成**: 按钮置灰，显示"领取"但不可点击
- **已完成**: 按钮变蓝色，可点击领取奖励
- **已领取**: 按钮消失或显示"已领取"

## 实际行为

- 任务触发条件可能错误（选择对话而非自由对话）
- 刷新时间在右侧
- 奖励按钮位置不对
- 按钮可能任务完成后才出现

## 排查方向

### FE 排查
- 文件: `frontend/src/views/PersonalCenterView.vue` 或 `frontend/src/components/TaskPanel.vue`
- 检查任务卡片布局
- 检查刷新时间显示位置
- 检查奖励按钮的位置和状态逻辑
- 检查任务触发条件的定义

### BE 验证
- 文件: `backend/app/api/v1/daily_task.py` 或相关服务
- 检查"对话达人"任务的触发条件配置
- 检查任务进度更新逻辑

## 修复方案

1. **修改任务触发条件**: 确保"对话达人"只在自由对话/角色聊天时触发
2. **调整布局**:
   - 刷新时间移到中间或右侧对齐
   - 奖励按钮移到任务描述右侧
3. **修改按钮状态逻辑**:
   - 按钮始终显示
   - 未完成时置灰
   - 已完成时变蓝色可点击
4. **检查任务触发逻辑**: 确认自由对话 API 调用时更新任务进度
