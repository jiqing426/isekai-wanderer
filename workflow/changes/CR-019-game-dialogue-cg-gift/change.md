# CR-019: 剧本游戏对话历史、CG触发、礼物弹框优化

## 变更目标
修复剧本游戏中的7个用户体验问题，涉及对话历史存储、CG触发逻辑、礼物弹框UI等。

## 影响范围
- 前端：GameView.vue、GiftModal.vue、HistoryDrawer.vue、FragmentMallView.vue
- 后端：game.py（对话历史存储）、scripts.py（CG节点配置）
- 数据库：game_dialogues 表、scripts 表（CG节点）

## 问题清单

### P0 - 核心功能问题
1. **对话历史未存储**：剧本游戏中对话历史没有保存，玩家无法查看之前的对话记录
2. **自定义对话无响应**：发送自定义对话后，旁白和选择按钮都没有变化，显示的是上一次的对话
3. **CG未触发**："月夜邂逅"剧本中第一张CG已经对话了八轮还是没有触发

### P1 - UI/UX优化
4. **礼物弹框不显示角色名字**：赠送礼物弹框中没有显示角色名字
5. **礼物弹框按钮布局**：取消、确认按钮需要放在一排
6. **删除手动存档按钮**：剧本游戏页左侧删除"手动存档"按钮
7. **碎片商城图片**：碎片商城 goods-icon 需要在数据库中添加图片

## 成功标准
- 对话历史正确存储并可查看
- 自定义对话后正确更新旁白和选择按钮
- CG在正确节点触发
- 礼物弹框显示角色名字，按钮布局正确
- 碎片商城显示图片

## 风险
- 对话历史存储可能影响性能（需要分页加载）
- CG节点配置需要确认剧本数据
- 自定义对话需要重新获取对话状态
