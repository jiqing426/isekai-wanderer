## 三、技术方案建议

### 3.1 剧本大厅

**后端**：
- 剧本表新增 `hot_value` 字段（bigint）
- 修改 `/discover` 或 `/scripts` 接口支持 category/sortType/page/size 参数
- SQL 强制二级排序：`ORDER BY score DESC, script_id ASC`
- 返回分类列表 categoryList

**前端**：
- 添加横向分类 Tab 栏
- 添加排序下拉选择器
- 实现滚动触底分页加载
- 切换条件时 page 重置为 1

### 3.2 页面优化

**后端**：
- 修复自由对话 3 个 500 接口
- 实现送礼记录接口（404→200）
- 实现签到逻辑（碎片规则+连续奖励）
- 实现游戏统计数据记录
- 修复头像上传返回 URL 而非 base64

**前端**：
- 游戏页面：进度条、角色信息、送礼入口
- 个人中心：签到、统计、快速继续
- 移动端：删除底部导航、修复滚动
- Header：跳转修复、头像逻辑、登录校验
- 设置页面：上传限制、保存逻辑、布局

### 3.3 登录小眼睛

**前端**：
- 密码框右侧添加眼睛图标按钮
- 点击切换 input type="password"/"text"
- 默认密文，失焦不自动隐藏
- 线性 SVG 图标，hover 透明度变化

## 五、风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 任务量大（25+ 项） | 高 | 分 P0/P1/P2 优先级，P0 先完成 |
| BE/FE 接口依赖 | 中 | BE 先完成接口，FE 再对接 |
| 自由对话 500 根因不明 | 中 | BE 先排查根因 |
| 头像上传 S3 配置 | 低 | 确认 S3 配置是否就绪 |
