# Character Spec — CR-008 V2

## 需求概述

修复角色页面数据展示问题，优化性格分析和好感度显示。

## 需求列表

### REQ-BUG-014: 性格数据 JSON 解析（P1）

**场景 1**: 解析性格标签 JSON
- 角色详情页性格数据不再显示原始 JSON
- 解析 JSON 后展示为标签列表
- 数据来源：`GET /characters/{id}` 的 `personality_tags` 字段

**场景 2**: JSON 格式错误
- 显示"暂无性格数据"
- 不显示错误堆栈

**验收标准**:
- AC-014-1: 性格数据不再显示原始 JSON
- AC-014-2: 解析 JSON 后展示为标签列表

### REQ-FEAT-030: 性格分析展示（P1）

**场景 1**: 展示性格标签
- 角色详情页显示"性格分析"卡片
- 展示性格标签（如"温柔"、"傲娇"、"活泼"）
- 每个标签使用不同颜色区分

**场景 2**: 标签描述说明
- 点击标签显示详细描述
- 描述来源：`personality_tags` 数组中的 `description` 字段
- 示例：温柔 - "总是用温和的方式对待他人"

**验收标准**:
- AC-030-1: 展示性格标签（如"温柔"、"傲娇"）
- AC-030-2: 每个标签附带描述说明
- AC-030-3: 数据来源：`GET /characters/{id}` 的 `personality_tags`

### REQ-BUG-015: 好感度"距离下一个"显示 NaN（P1）

**场景 1**: 显示正确数值
- 好感度卡片显示"距离下一个等级还需 X 点"
- 数据来源：`GET /characters/{id}` 的 `affection` 相关字段
- 计算逻辑：`next_level_threshold - current_affection`

**场景 2**: 好感度已满
- 当好感度达到最高等级
- 显示"已达最高等级"
- 不显示"距离下一个"

**场景 3**: 数据缺失
- 接口未返回好感度数据
- 显示"暂无好感度数据"
- 不显示 NaN

**验收标准**:
- AC-015-1: "距离下一个"显示正确数值或隐藏
- AC-015-2: 当好感度已满时显示"已满级"
- AC-015-3: 数据缺失时不显示 NaN

### REQ-FEAT-031: 语音试听 title（P2）

**场景 1**: 显示语音标题
- 角色详情页语音试听区域
- 每条语音显示标题（如"早安问候"、"战斗台词"）
- 数据来源：`voice_samples[].title`

**场景 2**: 标题缺失
- 显示"语音试听 #1"、"语音试听 #2"
- 使用序号作为默认标题

**验收标准**:
- AC-031-1: 每条语音试听显示标题
- AC-031-2: 标题来源：`voice_samples[].title`
- AC-031-3: 标题缺失时使用默认值

## 依赖

- BE: 需要确保角色接口返回完整数据
- BE: 需要确保 `personality_tags` 字段格式正确

## 风险

- 性格数据 JSON 格式不统一
- 需要前端容错处理
