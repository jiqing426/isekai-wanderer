# CR-021: 角色对话聊天界面

## 变更目标
在 Header 中增加角色聊天 Tab，实现完整的角色对话聊天界面

## 影响范围
- 前端 Header 导航组件
- 新增角色聊天页面（CharacterChatView.vue）
- 前端路由配置
- 后端 API（复用现有好感度、送礼、聊天接口）

## 成功标准
1. Header 显示角色聊天 Tab，点击可进入聊天页面
2. 左侧角色列表正确展示头像、名称、好感度进度条
3. 右侧聊天窗口支持消息展示、推荐话题、输入发送
4. 加号菜单支持送礼和查看送礼记录
5. 弹窗层级关系正确，交互流畅
