# Free Chat Spec — CR-008 V2

## 需求概述

修复自由对话相关缺陷，优化对话页面体验。

## 需求列表

### REQ-BUG-010: 话题接口修复（P0）

**场景 1**: 获取话题列表
- 用户进入自由对话页面
- 系统调用 `GET /game/{id}/free-chat/topics`
- 返回 200，包含 `topics: string[]`
- 前端显示话题列表

**场景 2**: 话题为空
- 接口返回 `topics: []`
- 前端显示"暂无话题"

### REQ-BUG-011: 历史接口修复（P0）

**场景 1**: 获取历史对话
- 用户进入自由对话页面
- 系统调用 `GET /game/{id}/free-chat/history`
- 返回 200，包含 `history: Message[]`
- 前端显示历史对话列表

**场景 2**: 历史为空
- 接口返回 `history: []`
- 前端显示"暂无历史对话"

### REQ-FEAT-020: 对话页面历史展示（P1）

**场景 1**: 进入页面加载历史
- 用户进入自由对话页面
- 自动加载最近 20 条历史对话
- 按时间倒序显示

**场景 2**: 滚动加载更多
- 用户滚动到历史底部
- 自动加载下一页（20条）
- 显示加载指示器

**场景 3**: 无更多历史
- 加载到最后一页
- 显示"没有更多历史对话"

### REQ-FEAT-021: 标题显示剧本和角色（P1）

**场景 1**: 显示剧本名称
- 对话页面标题下方显示剧本名称
- 数据来源：`GET /game/{id}/status` 的 `script_name`
- 无数据时显示"未知剧本"

**场景 2**: 显示角色名称
- 对话页面标题下方显示角色名称
- 数据来源：`GET /game/{id}/status` 的 `character_name`
- 无数据时显示"旁白"

## 验收标准

- AC-010-1: 话题接口返回 200
- AC-010-2: 响应包含 topics 数组
- AC-010-3: 前端话题列表正常显示
- AC-011-1: 历史接口返回 200
- AC-011-2: 响应包含 history 数组
- AC-011-3: 前端历史记录正常显示
- AC-020-1: 进入页面加载历史对话
- AC-020-2: 历史按时间倒序显示
- AC-020-3: 支持滚动加载更多
- AC-021-1: 标题下方显示剧本名称
- AC-021-2: 标题下方显示角色名称
- AC-021-3: 数据来源正确
