### 发现的问题

**CSS 选择器不匹配**:
- 测试脚本使用 `.achievement-item`, `.achievement-card` 选择器
- 实际 DOM 使用不同的 class 名称
- 导致测试脚本统计为"0 个成就项"
- **但截图证明成就列表正常显示**

**建议修复测试脚本**:
```typescript
// 当前选择器（不匹配）
const achievementList = await page.locator('.achievement-item, .achievement-card').count();

// 应改为（根据实际 DOM）
const achievementList = await page.locator('[class*="achievement"]').count();
// 或使用更具体的选择器
```
