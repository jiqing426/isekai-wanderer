### P1 - 功能缺陷

#### 2. 个人中心 - 碎片资产无数据
- **问题**: 累计获得、累计消费没有数据
- **类型**: BE + FE
- **分析**: 
  - BE: 检查 `/api/v1/shards/balance` 和 `/api/v1/shards/transactions` 接口
  - FE: 检查个人中心碎片资产展示逻辑
- **工作量**: BE 2h + FE 1h = 3h
- **对应需求**: FEAT-012/FEAT-013

#### 3. 自由对话 - 历史对话存储与展示
- **问题**: 聊天历史应该存储，没有时显示快速话题，有时显示历史
- **类型**: BE + FE
- **分析**:
  - BE: 检查 `/api/v1/game/{id}/free-chat/history` 接口（BE-O3）
  - FE: 检查 FreeChatView 历史加载逻辑
- **工作量**: BE 1h + FE 1h = 2h
- **对应需求**: FEAT-020

#### 4. 自由对话 - 角色身份错误（已规划）
- **问题**: 星月奇缘问角色名字，回答"雪乃"而非"沈星澜"
- **类型**: BE
- **分析**: 这是动态适配问题，已在 FC-01~06 任务中
- **工作量**: 已计入 FC 任务（6h）
- **对应需求**: FC-01~06

#### 5. 角色详情 - 语音试听缺少标题
- **问题**: 每条语音需要展示标题（甜美、阳光、冷酷等）
- **类型**: BE + FE
- **分析**:
  - BE: 检查 `/api/v1/characters/{id}/voices` 接口是否返回 title 字段
  - FE: 检查 CharacterDetailView 语音列表展示
- **工作量**: BE 0.5h + FE 0.5h = 1h
- **对应需求**: FEAT-031

#### 6. 角色详情 - 性格 JSON 直接展示
- **问题**: 名称下面直接展示性格 JSON，应该用中文展示
- **类型**: FE
- **分析**: FE 需要解析 JSON 并转换为中文标签
- **工作量**: FE 1h
- **对应需求**: BUG-014

#### 7. 角色详情 - 隐藏立绘和开始对话
- **问题**: 角色立绘、开始对话暂时隐藏
- **类型**: FE
- **分析**: 简单 UI 调整，注释或隐藏相关组件
- **工作量**: FE 0.5h

### P1 - 接口报错

#### 8. GET /api/v1/characters/gifts/catalog → 500
- **问题**: 礼物目录接口报错
- **类型**: BE
- **分析**: 
  - 检查 `backend/app/api/v1/characters.py` 是否有此接口
  - 如果没有，需要实现
  - 如果有，检查为什么返回 500
- **工作量**: BE 2h

#### 9. GET /api/v1/shards/balance → 500
- **问题**: 碎片余额接口报错
- **类型**: BE
- **分析**:
  - 接口存在于 `backend/app/api/v1/shards.py`
  - 检查为什么返回 500（可能是数据库表不存在或查询错误）
- **工作量**: BE 1h

#### 10. POST /api/v1/users/me/avatar → 401
- **问题**: 上传头像接口返回 401 Unauthorized
- **类型**: FE + BE
- **分析**:
  - FE: 检查是否正确传递 Authorization header
  - BE: 检查 `/api/v1/users/me/avatar` 接口认证逻辑
- **工作量**: FE 0.5h + BE 0.5h = 1h
