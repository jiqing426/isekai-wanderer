## 变更目标

构建完整的平台功能体系，提升用户留存和发现效率。聚焦 6 个核心模块（剧本发现/角色卡片/存档管理/碎片可视化/成就系统/每日任务增强），不含社区/UGC/支付（CEO 2026-07-22 澄清）。

## 成功标准

1. 用户可从发现页按类型/标签/难度筛选剧本，首页展示继续玩卡片
2. 用户可查看角色图鉴和好感度排行，关注角色并收到 PWA 通知
3. 用户可管理存档（重命名/删除/继续/快照/fork/结局收集）
4. 用户可查看碎片余额、消费记录和获取途径
5. 用户可查看成就墙和进度，领取奖励
6. 每日任务面板展示活跃度进度和宝箱

## 变更范围

### 6 大功能模块（CEO 澄清后修订）

#### 1. 剧本发现与推荐系统（P0）
**现状**：剧本列表是简单网格卡片，无分类、排序、搜索
**功能要求**：
1. **智能推荐**：根据用户已玩剧本类型、好感度高的角色类型，推荐相似剧本
2. **分类筛选**：按类型（恋爱/奇幻/悬疑/科幻）、标签（HE/BE/多结局）、难度筛选
3. **热度排行**：按游玩人数、评分、收藏数排序
4. **"继续玩"模块**：首页顶部大卡片展示用户最近一次未完成的剧本，一键继续

**建议路由**：`/discover`（独立发现页）+ HomeView 顶部"继续玩"卡片

#### 2. 角色卡片系统（P0）
**现状**：角色只在剧本内出现，无独立展示
**功能要求**：
1. **角色图鉴**：独立角色卡片展示页，含立绘/描述/背景故事/性格标签
2. **角色好感度排行榜**：展示用户与各角色的好感度进度
3. **角色对话预览**：未玩过的剧本也能看到角色示例对话
4. **收藏/关注角色**：关注后新剧本上线时推送通知

**建议路由**：`/characters`（角色列表）+ `/characters/:id`（角色详情）

#### 3. 存档与多线路管理（P0）
**现状**：game_sessions 表有存档数据，但 UI 无管理界面
**功能要求**：
1. **存档管理器**：查看所有历史存档，支持重命名、删除、继续游戏
2. **多线路并行**：同一剧本可同时开多个存档，探索不同分支
3. **存档快照**：关键决策点自动创建快照，支持"回到那个选择"
4. **结局收集进度**：每个剧本显示"已解锁结局 X/Y"，激发收集欲

**建议路由**：`/saves`（存档管理）+ 游戏内快捷入口

#### 4. 碎片经济体系可视化（P1）
**现状**：PaymentModal 只有充值，无清晰用途说明和消费记录
**功能要求**：
1. **碎片用途展示页**：图标+说明列出碎片能做什么（解锁章节/买装扮/抽卡/送礼物）
2. **消费记录流水**：每笔碎片消费明细
3. **碎片获取途径**：签到、完成任务、邀请好友、充值（多种方式对比）

**建议路由**：`/shards`（碎片中心）+ 各消费入口统一跳转

> 注：首充奖励/限时礼包已移出 CR-003（CEO 澄清）

#### 5. 成就系统（P1）
**现状**：数据库有 achievements 表，但 UI 无展示
**功能要求**：
1. **成就墙**：展示已获得和待解锁成就，带进度条
2. **成就类型**：
   - 剧情类：通关 X 个剧本、解锁全部结局
   - 社交类：发布 X 条社区帖子、获得 X 个赞
   - 收集类：收集 X 张 CG、解锁 X 个角色
   - 隐藏成就：特定选择触发的彩蛋
3. **成就奖励**：解锁成就获得碎片/装扮/称号

**建议路由**：`/achievements`

> 注：社交类成就已移出 CR-003（Q6 确认），改为活跃类

#### 6. 每日任务系统增强（P1）
**现状**：只有签到，任务系统无 UI
**功能要求**：
1. **每日任务列表**：玩一个剧本章节、在社区发一条评论、给角色送一次礼物
2. **任务进度条**：显示完成 X/Y 个任务，全部完成获额外碎片奖励
3. **活跃度宝箱**：活跃度到阈值解锁宝箱（随机碎片/道具）

**建议路由**：HomeView 内嵌任务面板 或 `/daily` 独立页

## 风险识别

1. **推荐算法复杂度**：需要用户行为数据分析，初期可用简单规则（热度 fallback）
2. **多存档并发**：需要处理存档冲突和存储成本（限制同剧本最多 5 存档）
3. **碎片经济平衡**：需要策划介入设计数值平衡（先用默认值）
4. **定时任务可靠性**：快照清理/任务刷新需要 cron 机制
5. **PWA 通知兼容性**：角色关注通知需确认 Web Share API 支持
