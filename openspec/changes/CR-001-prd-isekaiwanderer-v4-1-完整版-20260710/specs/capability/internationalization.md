# S012 国际化（P1）

**MAS（最小可用标准）**：英文 UI 翻译，不做多语言动态切换。

## Capability: 国际化

### Requirement: 英文 UI 翻译

系统所有 UI 文本（按钮/标签/提示/菜单）提供英文翻译，通过 i18n 框架实现。

#### Scenario: 英文 UI 展示

**Given** 系统部署版本为英文版
**When** 用户访问任意页面
**Then** 所有 UI 文本（按钮、标签、提示、菜单、错误信息）显示为英文
**And** 不包含未翻译的中文文本

#### Scenario: i18n 框架可扩展

**Given** 系统使用 i18n 框架（如 react-i18next）
**When** 后续需要新增语言（如日文）
**Then** 仅需添加语言文件，不改组件代码
