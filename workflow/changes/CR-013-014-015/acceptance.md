# CR-013/014/015 验收标准文档

## 验收概述

本文档定义了 CR-013（剧本详情）、CR-014（成就系统）、CR-015（角色设定）三个功能的验收标准。

## 验收标准

### CR-013: 剧本详情页面

#### 功能要求
- [ ] 返回完整的剧本详情信息
- [ ] 节点类型必须包含所有 6 种类型：fixed_scene, ai_dialog, choice_point, converge_node, cg_trigger, ending_node
- [ ] 所有 ID 必须使用 UUID v4 格式
- [ ] 返回正确的节点关系和解锁状态

#### 数据要求
- [ ] script_id: UUID v4 格式
- [ ] nodes: 数组，包含所有节点信息
- [ ] node_type: 枚举值，必须是 6 种类型之一
- [ ] node_id: UUID v4 格式
- [ ] is_unlocked: 布尔值，表示节点是否已解锁

#### 验收用例
1. 获取剧本详情，验证返回 6 种节点类型
2. 验证所有 ID 符合 UUID v4 格式
3. 验证节点解锁状态正确

### CR-014: 成就系统

#### 功能要求
- [ ] 返回完整的 15 个成就
- [ ] 每个成就必须包含所有必要字段
- [ ] 支持成就解锁和领取功能

#### 数据要求
- [ ] id: 成就 ID
- [ ] name: 成就名称
- [ ] description: 成就描述
- [ ] icon: 成就图标
- [ ] rarity: 稀有度（common/rare/epic）
- [ ] condition: 解锁条件
- [ ] reward: 奖励信息
- [ ] progress: 当前进度
- [ ] isUnlocked: 是否已解锁

#### 验收用例
1. 获取成就列表，验证返回 15 个成就
2. 验证每个成就包含所有必要字段
3. 验证成就解锁和领取功能正常

### CR-015: 角色设定

#### 功能要求
- [ ] 返回完整的角色信息
- [ ] 包含角色属性、对话风格、偏好设置
- [ ] 支持角色好感度系统

#### 数据要求
- [ ] id: 角色 ID
- [ ] name: 角色名称
- [ ] description: 角色描述
- [ ] avatar: 角色头像
- [ ] affection: 好感度信息
- [ ] dialogueStyle: 对话风格
- [ ] preferences: 偏好设置

#### 验收用例
1. 获取角色详情，验证包含所有必要字段
2. 验证好感度系统正常
3. 验证对话风格和偏好设置正确

1. BE 修复所有缺陷
2. QA 执行完整测试
3. Ops 执行回归测试

5. PM 确认发布条件
6. 执行发布
