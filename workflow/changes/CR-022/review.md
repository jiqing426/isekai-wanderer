| P2 | 缺少跳转角色详情按钮 | P0 | ChatWindow.vue |

#### 问题分析

**问题1: 角色数据不对**
- **根因**: `CharacterChatView.vue` 只调用了 `characterApi.getCharacters()`，该 API 不返回好感度数据
- **影响**: 左侧角色列表的好感度进度条和数值都是错误的
- **修复方案**: 同时调用 `affectionApi.getAffections()` 并合并数据

**问题2: 缺少跳转详情按钮**
- **根因**: `ChatWindow.vue` 的 `chat-header` 只实现了角色名称和好感度显示，未实现跳转功能
- **影响**: 用户无法从聊天页面快速跳转到角色详情页
- **修复方案**: 在 chat-header 添加"查看详情"按钮

### INTAKE 结论

**✅ 通过** - 问题清晰，修复方案明确，进入 DEVELOPMENT 阶段
