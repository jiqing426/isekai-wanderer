编码前缀 | 含义 | 用途 | 示例

四、P0功能详细拆解（二级功能 + AC验收标准 + ERR异常编码）
S00 入口/通用（W02/W03/W14）
F00-01 注册/登录
页面：W02 `/auth`
功能描述：Google OAuth / Discord OAuth / 邮箱注册，无需信用卡
AC验收标准：
AC00-01-01：支持三种登录方式，OAuth一键完成
AC00-01-02：邮箱注册：格式校验+密码强度+验证码
AC00-01-03：注册流程 ≤ 3步
AC00-01-04：注册完成后自动跳转 `/onboarding`
AC00-01-05：注册完成率 > 70%
ERR异常编码：
ERR00-01：OAuth授权失败 → 提示"登录失败，请重试或选择其他方式"
ERR00-02：邮箱已注册 → 提示"该邮箱已注册，请直接登录"
ERR00-03：网络超时 → Toast"网络连接异常，请重试"
F00-02 偏好引导（Onboarding 3步）
页面：W03 `/onboarding`
功能描述：3步引导：选择偏好→推荐剧本→进入首玩剧本
AC验收标准：
AC00-02-01：Step1 显示4种偏好类型（乙女/冒险/奇幻/悬疑），可单选/多选
AC00-02-02：Step2 根据偏好推荐1-2个首玩剧本，含简介和封面
AC00-02-03：Step3 点击"开始游玩"直接进入 `/play/:id/:session`
AC00-02-04：支持[跳过]→进入默认推荐剧本
AC00-02-05：首玩剧本在3分钟内进入第一个选择点
ERR异常编码：
ERR00-04：推荐数据加载失败 → 显示3个默认剧本供选择
F00-03 进度云端保存
页面：全局
功能描述：用户进度（剧本/好感度/CG/记忆）自动云端保存，跨设备可用
AC验收标准：
AC00-03-01：每次互动后自动保存进度（会话结束/节点推进时）
AC00-03-02：跨设备登录后可恢复上次游玩进度
AC00-03-03：保存延迟 < 500ms
ERR异常编码：
ERR00-05：保存失败 → 本地缓存+Toast"进度保存延迟，正在重试"

S03 剧本游玩页（W06）— 核心页面
F03-01 角色立绘展示区
页面：W06 `/play/:id/:session`
功能描述：动态表情切换立绘，根据对话内容自动切换表情
AC验收标准：
AC03-01-01：每个角色≥5种表情立绘（normal/happy/sad/angry/tense）
AC03-01-02：立绘根据对话情感自动切换表情
AC03-01-03：立绘切换有淡入淡出动画（300ms ease-out）
AC03-01-04：立绘支持响应式：桌面端全尺寸，移动端缩放适配
ERR异常编码：
ERR03-01：立绘加载失败 → 占位图（角色名首字母+灰色背景）
ERR03-02：表情映射缺失 → 使用默认normal表情
F03-02 背景图与BGM
页面：W06 `/play/:id/:session`
功能描述：场景背景图+BGM循环播放+音量控制
AC验收标准：
AC03-02-01：每个剧本≥3个场景背景图，根据剧情节点切换
AC03-02-02：每个剧本≥2首BGM，场景切换时自动切换BGM
AC03-02-03：BGM循环播放，支持淡入淡出切换（500ms）
AC03-02-04：音量控制：BGM音量/音效音量独立调节
AC03-02-05：支持BGM/音效开关（设置页配置，游玩页快捷切换）
ERR异常编码：
ERR03-03：BGM加载失败 → 静默降级，不阻塞游玩
ERR03-04：背景图加载失败 → 纯色背景（根据场景氛围色）
F03-03 流式文字对话区
页面：W06 `/play/:id/:session`
功能描述：AI叙事文本流式输出，打字机效果
AC验收标准：
AC03-03-01：文字流式动画帧率 ≥ 30fps
AC03-03-02：AI首token响应时间 < 2秒
AC03-03-03：AI完整响应时间 < 8秒（平均200字）
AC03-03-04：支持点击任意位置立即显示全文
AC03-03-05：打字速度可在设置中调整（1x/1.5x/2x/瞬时）
AC03-03-06：支持尊重 `prefers-reduced-motion`，关闭打字机效果
ERR异常编码：
ERR03-05：AI响应超时（>8s） → 显示"正在构思中..."，超时30s提示"生成超时，请重试"
ERR03-06：流式连接断开 → Toast"连接中断，正在重连..."
F03-04 选择界面（2-4个选项）
页面：W06 `/play/:id/:session`
功能描述：关键剧情节点展示2-4个选择项
AC验收标准：
AC03-04-01：选择项在AI回复完成后出现（500ms延迟动画）
AC03-04-02：每个选项文字清晰可辨，hover时高亮
AC03-04-03：键盘`↑`/`↓`选择选项，`Enter`确认
AC03-04-04：选择后有短暂的"选择确认"动画（200ms）
AC03-04-05：选择后推进到下一剧情节点
AC03-04-06：支持自由输入框（非选择项时的补充输入）
ERR异常编码：
ERR03-07：选择数据加载失败 → 降级为自由输入模式
ERR03-08：节点推进异常 → 回退到上一节点+Toast"剧情加载异常"
