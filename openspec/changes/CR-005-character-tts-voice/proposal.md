# CR-005: 角色详情语音试听 TTS 集成

## 为什么做

当前角色详情页语音试听使用浏览器 Web Speech API，存在以下问题：
- 音质差，不同浏览器/OS 表现不一致
- 无法差异化角色声音（所有角色用同一系统语音）
- 无法根据角色性别选择不同音色
- 用户体验低端，与产品"乙女向高品质"定位不符

升级为阿里云 CosyVoice TTS 可解决以上问题，提供高品质、可差异化的语音体验。

## 变更内容

1. **后端**：Character 模型新增 `tts_config`(JSON) + `gender`(string) 字段；新建 TTS 服务调用阿里云 API；角色创建时自动生成 4 情绪语音 mp3；修改 voices API 返回 audio_url
2. **前端**：重写 `useCharacterVoice.ts`（播放预生成音频 + Web Speech 降级）；修改 `CharacterDetailView.vue` 播放逻辑；更新 API 类型

## 不做范围

- 不集成 TTS 到游戏对话流程（仅试听场景）
- 不支持用户/运营自定义文案（使用固定模板）
- 不支持用户自选声音角色
- 不支持多语言语音
- 不新增语音试听统计/埋点
- 不新增"重新生成语音"用户入口（仅管理端接口）

## 成功标准

- 角色创建后 4 个情绪语音全部可播放，音质明显优于 Web Speech API
- 阿里云 API 失败时自动降级到 Web Speech API，用户无感知
- 音频文件可通过 URL 直接访问，CDN 可缓存

## 影响范围

- 数据库：Character 表新增 2 字段（需迁移）
- 文件系统：新增 `/app/static/voices/` 目录
- API：`GET /characters/{id}/voices` 返回结构变更
- 前端：`useCharacterVoice.ts` 重写、`CharacterDetailView.vue` 修改
