# CR-019 测试计划

## 测试范围
- 对话历史存储和显示
- 自定义对话响应
- CG触发逻辑
- 礼物弹框UI
- 碎片商城图片显示

## 测试用例

### TC-001: 对话历史存储测试
1. 开始游戏，进行3轮对话选择
2. 打开历史对话抽屉
3. 验证：显示3轮对话记录，包含角色名和对话内容
4. 进行1轮自定义输入
5. 验证：历史记录包含自定义输入内容

### TC-002: 自定义对话响应测试
1. 在游戏中发送自定义输入"你好"
2. 验证：StoryPanel显示新的对话内容
3. 验证：选择按钮正确更新（如果有变化）
4. 验证：如果是第一次对话，显示成就弹框

### TC-003: CG触发测试
1. 开始"月夜邂逅"剧本
2. 进行对话直到CG节点
3. 验证：CG图片正确显示
4. 验证：CG收集状态更新

### TC-004: 礼物弹框UI测试
1. 点击送礼按钮
2. 验证：弹框标题显示"送给 {角色名}"
3. 验证：取消和确认按钮在同一行
4. 验证：按钮布局正确

### TC-005: 手动存档按钮测试
1. 进入剧本游戏页
2. 验证：左侧栏不显示"手动存档"按钮
3. 验证：其他按钮（存档、历史、自由对话等）正常显示

### TC-006: 碎片商城图片测试
1. 进入碎片商城页面
2. 验证：商品列表显示图片
3. 验证：图片加载正确
