# 异世界漫游者 - 后台管理系统功能清单

## 一、用户管理

### 1.1 用户列表
- 用户基本信息（ID、邮箱、昵称、头像）
- 账号状态（是否验证、是否管理员）
- 注册时间、最后登录时间
- 订阅等级（free/basic/standard/premium）
- 操作：查看详情、编辑、禁用/启用、删除

### 1.2 用户详情
- 基础信息编辑
- 订阅历史
- 游戏统计（完成剧本数、总对话数、选择次数）
- 好感度记录（与所有角色的好感度）
- 游戏存档列表
- 碎片余额和交易记录
- 登录设备管理

### 1.3 OAuth账号管理
- 第三方登录绑定（Google、Discord）
- 解绑操作

---

## 二、剧本管理

### 2.1 剧本列表
- 剧本基本信息（标题、描述、类型、封面）
- 热度值、创建时间
- 章节数量、角色数量
- 操作：编辑、删除、上下架

### 2.2 剧本编辑
- 基础信息（标题、描述、类型、封面图）
- 作者信息
- 热度值设置
- 集合点数量配置

### 2.3 章节/路线管理
- 章节列表（按章节号排序）
- 章节类型（encounter/daily/conflict/convergence）
- 分支类型（main/branch_a/branch_b/secret）
- 分支条件配置
- 操作：新增、编辑、删除、排序

### 2.4 剧情节点管理
- 节点类型（preset/transition/choice/ending/ai_dialog等）
- 节点内容编辑（文本、情感、背景图）
- 角色绑定（公共节点/角色专属节点）
- 节点关系图（可视化）
- 操作：新增、编辑、删除、复制

### 2.5 选择项管理
- 选择文本
- 下一节点指向
- 好感度变化值
- 隐藏条件（好感度阈值）
- 提示文本（hover显示）
- 操作：新增、编辑、删除

### 2.6 角色管理
- 角色基本信息（名称、描述、头像）
- 性格特征
- 对话风格
- 是否可扮演
- 解锁类型（free/paid/subscription）
- 解锁价格
- 操作：新增、编辑、删除

---

## 三、订阅管理

### 3.1 订阅计划配置
- 等级设置（free/basic/standard/premium）
- 每月碎片配额
- 权益配置

### 3.2 用户订阅记录
- 订阅历史列表
- 订阅状态（active/cancelled/expired）
- 到期时间
- 碎片发放记录
- 操作：手动续期、取消、调整等级

---

## 四、礼物管理

### 4.1 礼物商城
- 礼物列表（名称、描述、价格、好感度加成）
- 图标管理
- 上架/下架状态
- 操作：新增、编辑、删除、排序

### 4.2 送礼记录
- 送礼历史（用户、角色、礼物、时间）
- 好感度变化记录
- 碎片消费统计
- 筛选：按用户、角色、时间范围

---

## 五、好感度管理

### 5.1 好感度列表
- 用户-角色好感度记录
- 当前好感度值、等级
- 最后更新时间
- 操作：查看详情、手动调整

### 5.2 好感度历史

- 筛选：按用户、角色、时间范围

---

## 六、对话记录管理

### 6.1 游戏会话列表
- 会话基本信息（用户、剧本、角色、状态）

### 6.2 会话详情

- 好感度变化轨迹

### 6.3 自由对话记录

- 对话消息记录
- 用户输入、AI回复
- 时间戳

### 6.4 社区聊天管理
- 话题列表
- 消息列表
- 操作：删除消息、禁言用户

## 七、资产管理

## 技术实现建议

### 前端技术栈
- Vue 3 + TypeScript
- Element Plus / Ant Design Vue
- Vue Router
- Pinia（状态管理）
- Axios

### 后端技术栈
- FastAPI（复用现有后端）
- SQLAlchemy（ORM）
- JWT认证
- RBAC权限控制

### 数据库
- PostgreSQL（复用现有数据库）
- Redis（缓存、会话管理）

### 部署
- Docker容器化
- Nginx反向代理
- 独立域名/子域名（admin.example.com）
