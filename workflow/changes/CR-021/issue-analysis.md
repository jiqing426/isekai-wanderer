## 新增需求：流式对话功能

**提出时间**: 2026-07-29 13:56:00  
**提出人**: 用户  
**优先级**: P0

### 需求描述

角色聊天需要实现流式对话功能：
1. 用户发送文字后，请求 NPC 接口
2. 使用 SSE (Server-Sent Events) 流式返回 NPC 回复
3. 前端实现打字机效果，逐字显示 NPC 回复
4. 等待响应时显示 loading 状态

### 技术要点

**后端**:
- 实现 SSE 流式接口 `/api/v1/character-chat/{character_id}/stream`
- 复用现有的 SSE 模式（参考 `game.py` 中的 `dialogue/stream`）
- 流式返回 NPC 回复内容

**前端**:
- 使用 `EventSource` 或 `fetch` 的 `ReadableStream` 接收流式数据
- 实现打字机效果，逐字显示 NPC 回复
- 等待响应时显示 loading 动画
- 保存完整的对话记录到数据库

### 参考实现

后端已有 SSE 实现：
- 文件：`backend/app/api/v1/game.py`
- 接口：`/game/{session_id}/dialogue/stream`
- 使用 `StreamingResponse` 和 `text/event-stream`

### 分配

- **BE**: 实现角色聊天流式接口
- **FE**: 实现流式接收和打字机效果
