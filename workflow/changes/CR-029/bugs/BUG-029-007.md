# BUG-029-007: AI 记忆显示数量错误和语言问题

**优先级**: P1  
**发现时间**: 2026-08-04 09:18  
**报告人**: PL  

## 问题描述

个人中心页面中 AI 记忆存在两个问题：

1. **显示数量错误**: 一共 109 条记忆，但页面只展示三四条
2. **语言问题**: 重要事件中显示英文而不是中文

## 预期行为

1. 显示所有 109 条记忆（或提供分页/加载更多功能）
2. 重要事件显示中文内容

## 实际行为

1. 只显示 3-4 条记忆
2. 重要事件显示英文

## 可能原因

### 问题 1: 显示数量错误
1. **FE 分页问题**: 可能默认只加载第一页（如 limit=10），但没有分页控件
2. **API 限制**: 后端 API 可能默认返回少量记录
3. **数据查询问题**: SQL 查询可能有限制条件
4. **前端渲染问题**: 可能只渲染了部分数据

### 问题 2: 语言问题
1. **数据源问题**: 记忆中存储的就是英文（可能是系统提示或默认内容）
2. **翻译问题**: 前端没有翻译英文内容
3. **Prompt 问题**: AI 生成记忆时使用了英文
4. **分类问题**: "重要事件"分类下的记忆可能是英文模板

## 排查方向

### FE 排查
- 文件: `frontend/src/views/PersonalCenterView.vue` 或 `frontend/src/components/MemoryCard.vue`
- 检查记忆列表的 API 调用参数（是否有 limit/offset）
- 检查是否有分页或"加载更多"功能
- 检查记忆内容的渲染逻辑（是否有翻译处理）

### BE 排查
- 文件: `backend/app/api/v1/memory.py` 或 `backend/app/services/memory_service.py`
- 检查记忆查询 API 的默认 limit
- 检查记忆内容的生成逻辑（为什么是英文）
- 检查"重要事件"分类的记忆内容

### 数据排查
```sql
-- 检查记忆总数
SELECT COUNT(*) FROM memories;

-- 检查记忆内容语言
SELECT id, content, category, created_at 
FROM memories 
WHERE category = 'important_event'
ORDER BY created_at DESC
LIMIT 10;

-- 检查是否有中文记忆
SELECT COUNT(*) FROM memories WHERE content LIKE '%[一-龥]%';
```

## 修复方案

### 问题 1: 显示数量
- **方案 A**: FE 增加分页或"加载更多"按钮
- **方案 B**: BE 修改默认 limit（如改为 50）
- **方案 C**: FE 一次性加载所有记忆（如果数据量不大）

### 问题 2: 语言问题
- **方案 A**: BE 修改记忆生成 Prompt，强制使用中文
- **方案 B**: FE 检测英文内容并翻译（不推荐）
- **方案 C**: 清理英文记忆数据，重新生成中文记忆
