# Spec: 存档管理页角色筛选

### Requirement: 存档管理页按角色筛选

#### Scenario: 存档管理页展示角色筛选标签栏
- **Given** 用户进入存档管理页
- **When** 页面加载完成
- **Then** 顶部展示标签栏：「全部」+ 各角色名标签
- **And** 「全部」标签默认选中
- **And** 角色标签仅显示用户有存档的角色（去重）

#### Scenario: 玩家点击角色标签筛选
- **Given** 存档管理页已加载
- **When** 玩家点击某角色标签（如「爱丽丝」）
- **Then** 列表仅显示 character_name='爱丽丝' 的存档
- **And** 其他角色的存档不显示

#### Scenario: 玩家点击「全部」标签
- **Given** 玩家当前选中某角色标签
- **When** 玩家点击「全部」标签
- **Then** 列表恢复显示所有存档
- **And** 「全部」标签高亮选中

#### Scenario: 筛选标签栏无角色时不显示
- **Given** 用户所有 GameSession 的 character_id 均为 NULL
- **When** 用户进入存档管理页
- **Then** 不展示角色筛选标签栏（仅显示「全部」或不显示筛选区域）

#### Scenario: 角色筛选支持分页
- **Given** 某角色存档数量超过单页限制
- **When** 玩家点击该角色标签
- **Then** 接口支持 character_id 筛选参数
- **And** 返回分页结果
