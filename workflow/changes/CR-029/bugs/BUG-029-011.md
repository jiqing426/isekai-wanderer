# BUG-029-011: 每日任务卡片布局不符合需求

**优先级**: P1  
**发现时间**: 2026-08-04 10:25  
**报告人**: PL  

## 问题描述

用户反馈：每日任务卡片布局不符合需求，之前的修复理解错误。

## 正确需求

### 布局要求

```
┌─────────────────────────────────────────────────────────┐
│ card-header                                             │
│ [📋 每日任务]    [每日 0:00 刷新]    [🎁 全完成奖励]    │
├─────────────────────────────────────────────────────────┤
│ 💬 对话达人                                             │
│ 完成1次对话（任意剧本）              💎 +3碎片  [领取]   │
│                                                         │
│ 🎯 选择大师                                             │
│ 做出1次选择（任意剧本）              💎 +3碎片  [领取]   │
│                                                         │
│ 👤 角色探索                                             │
│ 查看1个角色档案（W09）               💎 +2碎片  [领取]   │
└─────────────────────────────────────────────────────────┘
```

### 关键布局点

1. **card-header 三栏布局**：
   - 左侧：标题 "📋 每日任务"
   - 中间：刷新时间 "每日 0:00 刷新"
   - 右侧：全完成奖励按钮（全部任务完成后显示）

2. **任务列表**：
   - 每个任务独立一行
   - 左侧显示任务标题和描述
   - 右侧显示奖励和领取按钮

3. **任务定义**：
   - 💬 对话达人：完成1次对话（任意剧本）→ +3碎片
   - 🎯 选择大师：做出1次选择（任意剧本）→ +3碎片
   - 👤 角色探索：查看1个角色档案（W09）→ +2碎片

4. **全完成奖励**：
   - 全部3个任务完成后，card-header 右侧显示奖励按钮
   - 点击领取 +5碎片

## 当前代码问题

`PersonalCenterView.vue` 第 153-200 行：
- 刷新时间 `<div class="reset-info-center">` 在 tasks-list 外面，不在 card-header 中间
- 全完成奖励按钮在 tasks-list 下面，不在 card-header 右侧

## 修复方案

### FE 修复

1. **修改 card-header 结构**：
   ```vue
   <div class="card-header">
     <h3 class="card-title">📋 每日任务</h3>
     <div class="reset-info">每日 0:00 刷新</div>
     <div v-if="allTasksCompleted && !allClaimed" class="all-complete-btn">
       <n-button type="success" size="small" @click="claimAllTasks">
         🎁 全完成奖励
       </n-button>
     </div>
   </div>
   ```

2. **添加样式**：
   ```css
   .card-header {
     display: grid;
     grid-template-columns: 1fr auto 1fr;
     align-items: center;
   }
   .card-title { justify-self: start; }
   .reset-info { justify-self: center; }
   .all-complete-btn { justify-self: end; }
   ```
