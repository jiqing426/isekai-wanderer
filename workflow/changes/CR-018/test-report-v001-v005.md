## 问题分析

### 共同问题：UI 选择器不匹配

所有 5 个测试都遇到相同问题：**API 层功能正常，但 Playwright 测试选择器未匹配前端实际 DOM 结构**。

**原因分析**:
1. 前端使用 Vue 组件（如 `<ChoicePanel>`、`<AchievementList>`）
2. 测试选择器使用通用类名（`.choice-btn`、`.achievement-item`）
3. 实际 DOM 结构可能使用不同的类名或组件结构

**建议解决方案**:
1. 检查前端组件实际渲染的 DOM 结构
2. 更新测试选择器以匹配实际类名
3. 或使用 `data-testid` 属性提高测试稳定性
