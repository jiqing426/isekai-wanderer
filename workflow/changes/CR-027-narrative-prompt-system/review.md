### 决策依据

1. **业务价值清楚** — 六层 Prompt 引擎是叙事核心能力，直接解决：
   - NPC "全知"问题（角色只能知道自己的经历）
   - 剧情单调问题（循序渐进流露秘密、制造情绪冲突）
   - 开放沙盒自由交互支持
   
2. **与 PRD 对齐** — 对应 S001（叙事一致性引擎）和 S003（跨会话记忆）的深化实现，属于 MVP 核心范围

3. **目标用户/场景清楚** — 乙女玩家（情感深度）、冒险者（多线体验）的核心诉求

### 范围边界

**✅ 纳入本轮范围：**
- Lorebook 世界知识库系统（基础 CRUD + 场景标签注入）
- 场景配置系统（基础场景-标签绑定）
- NPC 人物内核扩展（personality_traits: 渴望/恐惧/秘密）
- Prompt 拼接引擎（六层结构）
- Token 预算控制器（2300 tokens 上限）
- 前端管理界面（Lorebook + 场景配置，最小可用）

**❌ 不做 / 延后：**
- Lorebook 智能检索优化（MVP 用简单标签匹配，RAG 语义检索延后）
- 动态记忆区的向量检索增强（依赖 PRE-02 向量数据库选型确认后再深化）
- 多语言 Prompt 支持（MVP 仅中文）
- Prompt 模板可视化编辑器（MVP 用配置文件，不做 UI 编辑）
- Token 用量统计与计费（MVP 不做）
