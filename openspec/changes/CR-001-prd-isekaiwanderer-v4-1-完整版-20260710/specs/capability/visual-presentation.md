# S006 基础视觉呈现

## REQ-005: 基础视觉呈现

### 需求概述

二次元风格的视觉体验底线。每角色 ≥5 种表情立绘，每剧本 ≥3 个场景背景图 + 2 首 BGM，流式文字动画 ≥30fps，首屏加载 <3s。

### Requirement: 角色立绘与表情切换

**ID**: REQ-005-R01  
**优先级**: P0  

每个角色至少 5 种表情立绘（默认/开心/悲伤/愤怒/惊讶），对话中根据 AI 输出的情绪标签自动切换表情。

#### Scenario: 对话中角色表情随情绪切换

- **Given** 角色 A 当前表情为"默认"，AI 输出对话带有"开心"情绪标签
- **When** 对话文本开始展示
- **Then** 角色 A 立绘切换为"开心"表情，切换动画平滑（≤200ms）

#### Scenario: 无情绪标签时保持默认表情

- **Given** AI 输出的对话没有情绪标签
- **When** 对话文本展示
- **Then** 角色 A 保持当前表情不变

### Requirement: 场景背景图

**ID**: REQ-005-R02  
**优先级**: P0  

每个剧本至少 3 个场景背景图（如教室/森林/城堡），剧情推进到不同场景时自动切换背景。

#### Scenario: 剧情推进切换场景背景

- **Given** 当前场景为"教室"，剧情节点指定下一场景为"森林"
- **When** 节点切换
- **Then** 背景图从"教室"淡入切换到"森林"，过渡动画 ≤500ms

### Requirement: BGM 播放

**ID**: REQ-005-R03  
**优先级**: P0  

每个剧本至少 2 首 BGM，根据场景氛围自动切换。支持静音/音量调节。

#### Scenario: 场景切换时 BGM 跟随切换

- **Given** 当前 BGM 为"日常轻松"，场景切换到"战斗紧张"氛围
- **When** 新场景加载完成
- **Then** BGM 从"日常轻松"淡出切换到"战斗紧张"

#### Scenario: 用户静音

- **Given** BGM 正在播放
- **When** 用户点击静音按钮
- **Then** BGM 停止播放，按钮切换为静音状态图标

### Requirement: 流式文字动画

**ID**: REQ-005-R04  
**优先级**: P0  

对话文本以流式打字效果展示，帧率 ≥30fps。用户可点击跳过动画直接显示全部文本。

#### Scenario: 对话文本流式展示

- **Given** AI 返回一段 50 字的对话文本
- **When** 文本开始展示
- **Then** 文字逐字/逐段出现，动画流畅（≥30fps），全部展示完毕 ≤3s

#### Scenario: 用户点击跳过文字动画

- **Given** 文字动画正在播放中
- **When** 用户点击对话区域
- **Then** 全部文本立即显示，动画停止

### Requirement: 首屏加载性能

**ID**: REQ-005-R05  
**优先级**: P0  

页面首次加载（从输入 URL 到可交互）<3s（3G Fast 网络条件下）。

#### Scenario: 首屏加载

- **Given** 用户在 3G Fast 网络环境下打开游戏首页
- **When** 页面加载
- **Then** 从导航开始到可交互状态 <3s

### 不做范围（本 CR）

- 不做 Live2D 动态立绘（MVP 用静态立绘 + 表情切换）
- 不做 CG 画廊系统（P1）
- 不做自定义角色立绘

### R/C/U/D 完整性

| 动作 | 是否包含 | 说明 |
| --- | --- | --- |
| Create | 是 | 美术资源的创建和上传 |
| Read | 是 | 运行时加载和展示资源 |
| Update | 是 | 资源替换/版本更新 |
| Delete | 否 | MVP 不删除资源，仅替换 |

### 下游约束

- 需要美术资源确认（PRE-03）：立绘/背景/BGM 的获取方式和产出计划
- 需要前端实现：流式文字渲染、资源预加载策略、表情切换动画
- 需要 API 契约：资源 URL 获取、CDN 配置
- 验收需要浏览器交互：表情切换、场景切换、文字动画、静音操作
- 验收需要性能测试：首屏加载时间测量
