# S018 Push 通知（P1）

**MAS（最小可用标准）**：PWA 通知权限提示，不做主动推送。

## Capability: Push 通知

### Requirement: PWA 通知权限请求

系统在用户首次访问时请求通知权限，获取权限后仅在用户主动触发时发送通知。

#### Scenario: 首次访问请求通知权限

**Given** 用户首次访问游戏（PWA）
**When** 页面加载完成
**Then** 系统弹出通知权限请求（浏览器原生提示）
**And** 用户授权后记录权限状态

#### Scenario: 用户手动触发通知测试

**Given** 用户已授权通知权限
**When** 用户在设置页面点击"测试通知"
**Then** 系统发送一条 PWA 通知（含游戏名称和测试文本）
