# CR-019 审查记录

## INTAKE 阶段审查

### 变更概述
接收7个剧本游戏用户体验问题，涉及对话历史存储、CG触发、礼物弹框UI等。

### 问题分类

#### P0 - 核心功能问题（3个）
1. **对话历史未存储** - 后端已有 store_dialogue API，但前端未调用
2. **自定义对话无响应** - submitCustomInput 后需要 fetchDialogue 更新状态
3. **CG未触发** - 需要检查"月夜邂逅"剧本的CG节点配置

#### P1 - UI/UX优化（4个）
4. **礼物弹框不显示角色名字** - GiftModal 需要接收 character_name prop
5. **礼物弹框按钮布局** - CSS 调整
6. **删除手动存档按钮** - GameView.vue 移除按钮
7. **碎片商城图片** - 数据库添加图片URL

### 影响范围
- 前端：GameView.vue、GiftModal.vue、FragmentMallView.vue
- 后端：game.py（已确认 store_dialogue API 存在）
- 数据库：scripts 表（CG节点配置）

### 风险识别
1. 对话历史存储需要前端在每次对话后调用 store_dialogue API
2. CG触发需要确认剧本数据中的CG节点配置
3. 自定义对话需要重新获取对话状态

### 依赖
- 无外部依赖
- 需要确认"月夜邂逅"剧本的CG节点数据
