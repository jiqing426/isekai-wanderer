# BUG-029-003: 送礼记录只显示当前角色而非所有角色

**优先级**: P1  
**发现时间**: 2026-08-04 09:18  
**报告人**: PL  

## 问题描述

剧本游戏中送礼记录页面，点击后只查看当前角色的送礼记录，而不是所有角色的送礼记录。

## 预期行为

送礼记录页面应该显示玩家与**所有角色**的送礼历史记录，或者提供切换角色的筛选功能。

## 实际行为

只显示当前对话角色的送礼记录。

## 可能原因

1. **FE 过滤逻辑问题**: 送礼记录页面可能硬编码使用当前对话的 `character_id` 过滤
2. **API 参数问题**: 请求送礼记录时传入了 `character_id` 参数，导致只返回该角色的记录
3. **数据设计问题**: 后端 API 可能不支持查询所有角色的送礼记录

## 排查方向

### FE 排查
- 文件: `frontend/src/views/GiftView.vue` 或 `frontend/src/components/GiftModal.vue`
- 检查送礼记录列表的 API 调用是否传入了 `character_id`
- 检查是否有"所有角色"的筛选选项

### BE 排查
- 文件: `backend/app/api/v1/gift.py`
- 检查送礼记录 API 是否支持不传 `character_id` 参数（返回所有角色）
- 检查 SQL 查询是否按 `character_id` 过滤

## 修复方案

**方案 A（推荐）**: 显示所有角色的送礼记录，按角色分组或提供筛选
**方案 B**: 保留当前角色过滤，但增加"查看所有角色"选项
