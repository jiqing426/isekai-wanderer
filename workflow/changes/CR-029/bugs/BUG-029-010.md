# BUG-029-010: 每日任务布局和奖励定义修正

**优先级**: P1  
**发现时间**: 2026-08-04 09:38  
**报告人**: PL  

## 问题描述

之前的 BUG-029-006 修复理解有误，需要重新调整。

## 正确需求

### 布局要求

```
┌─────────────────────────────────────────────────┐
│ card-header                                     │
│ [标题]          [每日 0:00 刷新]    [全完成奖励] │
├─────────────────────────────────────────────────┤
│ 对话达人：完成1次对话（任意剧本）    → +3碎片    │
│ 选择大师：做出1次选择（任意剧本）    → +3碎片    │
│ 角色探索：查看1个角色档案（W09）     → +2碎片    │
└─────────────────────────────────────────────────┘
```

- **card-header 中间**：每日 0:00 刷新时间
- **card-header 右侧**：全部任务完成后的奖励按钮（+5碎片）

### 任务定义

| 任务 | 触发条件 | 奖励 |
|------|----------|------|
| 对话达人 | 完成1次对话（任意剧本） | +3碎片 |
| 选择大师 | 做出1次选择（任意剧本） | +3碎片 |
| 角色探索 | 查看1个角色档案（W09） | +2碎片 |
| **全完成奖励** | 上述3个任务全部完成 | **+5碎片** |

### 交互逻辑

- 单个任务完成后，奖励按钮置灰
- 全部3个任务完成后，奖励按钮变蓝色可点击，显示"领取 +5碎片"
- 点击领取后，发放5碎片奖励

## 修复方案

### FE 修复

1. **布局调整**：
   - 刷新时间移到 card-header 中间
   - 右侧添加"全完成奖励"按钮

2. **按钮状态逻辑**：
   - 监听3个任务的完成状态
   - 全部完成时按钮变蓝色可点击
   - 点击后调用领取 API

### BE 修复

1. **任务定义修正**：
   - 对话达人：target=1（不是3），reward=3（不是5）
   - 选择大师：target=1，reward=3
   - 角色探索：target=1，reward=2

2. **全完成奖励 API**：
   - 新增 `/daily-tasks/claim-all` 端点
   - 检查3个任务是否全部完成
   - 发放5碎片奖励
