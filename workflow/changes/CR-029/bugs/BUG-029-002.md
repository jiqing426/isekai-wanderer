# BUG-029-002: 自由对话点击其他角色仍显示主角对话

## 问题描述

用户反馈：剧本游戏中自由对话，点击其他角色进入为什么还是主角的对话，而不是其他角色的对话。

## 问题分析

### 代码定位

**文件**: `frontend/src/views/GameView.vue`

```javascript
function goToFreeChat() {
  if (!game.currentSession) {
    message.warning('请先开始游戏');
    return;
  }
  router.push({
    path: `/game/${game.currentSession.id}/free-chat`,
    query: {
      character: characterDisplayName.value,
      characterId: gameStatus?.character_id,  // ❌ BUG: 使用玩家扮演的角色
      scriptId: game.currentScript?.id,
    },
  });
}
```

**问题**: 
- `gameStatus.character_id` 是 CR-029 新增的字段，表示**玩家扮演的角色**（如沈星澜）
- 但用户点击"其他角色"（如白夜、暮雪）时，应该传递**被点击角色的 ID**
- 现在无论点击哪个角色，都传递的是玩家角色 ID，导致自由对话始终显示主角

### 数据流分析

1. **剧本游戏**
   - `game_sessions.character_id` = 玩家选择的角色（如沈星澜）
   - 玩家以该角色身份进行游戏

2. **自由对话**
   - 应该支持玩家与**任何 NPC** 对话
   - 点击白夜 → 应该与白夜对话
   - 点击暮雪 → 应该与暮雪对话
   - 但现在点击任何角色 → 都与玩家角色（沈星澜）对话

### 根本原因

CR-029 的 `goToFreeChat()` 函数硬编码使用 `gameStatus.character_id`（玩家角色），没有接收用户点击的角色 ID。

## 修复方案

### FE 修复

1. **修改 `goToFreeChat()` 函数签名**
   ```javascript
   function goToFreeChat(targetCharacterId?: string, targetCharacterName?: string) {
     if (!game.currentSession) {
       message.warning('请先开始游戏');
       return;
     }
     
     // 如果没有指定角色，使用默认逻辑
     const characterId = targetCharacterId || gameStatus?.character_id;
     const characterName = targetCharacterName || characterDisplayName.value;
     
     router.push({
       path: `/game/${game.currentSession.id}/free-chat`,
       query: {
         character: characterName,
         characterId: characterId,
         scriptId: game.currentScript?.id,
       },
     });
   }
   ```

2. **在角色列表/按钮中传递角色 ID**
   ```vue
   <!-- 角色选择按钮 -->
   <n-button @click="goToFreeChat(npc.id, npc.name)">
     {{ npc.name }}
   </n-button>
   ```

3. **检查角色列表组件**
   - 文件：`frontend/src/components/CharacterList.vue`
   - 检查点击事件是否正确传递角色 ID

### BE 验证

1. **检查 `/api/v1/chat/free` 接口**
   - 是否正确接收 `character_id` 参数
   - 是否返回对应角色的对话

2. **检查自由对话历史**
   - 文件：`backend/app/api/v1/chat.py`
   - 检查 `get_free_chat_history()` 是否按 `character_id` 过滤

## 测试用例

1. 选择沈星澜开始游戏
2. 点击"自由对话"按钮
3. 点击白夜角色
4. **预期**：进入与白夜的对话，显示白夜的名字和头像
5. **实际**：进入与沈星澜的对话（BUG）
