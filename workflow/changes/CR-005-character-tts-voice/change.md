# CR-005: 角色详情语音试听 TTS 集成

## 变更目标
将角色详情页的语音试听功能从 Web Speech API 升级为阿里云 CosyVoice TTS，预生成音频存储到数据库和文件系统。

## 影响范围
- 后端：Character 模型、TTS 服务、API 接口、静态文件服务
- 前端：语音播放逻辑、API 层
- 数据库：新增 tts_config 和 gender 字段
- 配置：新增 TTS 相关环境变量

## 成功标准
- 角色创建时自动生成 4 个情绪的语音文件
- 语音试听页面可播放预生成的音频
- 阿里云 API 失败时降级到 Web Speech API
- 音频文件可通过 URL 直接访问

## 功能清单
1. 数据库模型变更（tts_config、gender 字段）
2. TTS 服务实现（阿里云 CosyVoice 集成）
3. 配置变更（TTS 环境变量）
4. API 接口修改（voices 接口、重新生成接口）
5. 静态文件服务（voices 目录挂载）
6. 前端 API 层更新
7. 前端语音播放逻辑重写

## 风险
- 阿里云 TTS API 调用失败导致语音生成失败
- 音频文件存储路径权限问题
- 数据库迁移可能影响现有数据
- 前端降级逻辑复杂度增加
