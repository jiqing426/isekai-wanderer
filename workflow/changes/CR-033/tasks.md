## 任务分配

### BE 任务

#### T-033-BE-001: 修复剧本详情章节解锁逻辑
**优先级**：P0  
**负责人**：BE  
**问题描述**：剧本详情页中，第一到第三章节都显示为锁定状态，用户无法开始游戏  
**根因**：`get_script` API 的 `is_unlocked` 字段判断逻辑有缺陷

**修复方案**：
1. 按 `chapter_number` 排序所有路线
2. 第一个章节默认解锁（无论用户是否玩过）
3. 前置章节 `completed` → 解锁下一个章节
4. 正在进行的章节（`active`）保持解锁

**验收标准**：
- 新用户可以点击第一个章节开始游戏
- 完成第一章后，第二章自动解锁
- 正在进行的章节保持解锁状态
- 未完成的后续章节显示为锁定状态

**允许写入范围**：
- `backend/app/api/v1/scripts.py`（`get_script` 函数）

**验证方式**：
1. 创建新用户，访问剧本详情页
2. 验证第一个章节显示为解锁状态
3. 开始游戏并完成第一章
4. 返回剧本详情页，验证第二章已解锁

**回滚方案**：git revert
