# BUG-029-004: 好感度刻度只有 0-80 没有 100

**优先级**: P1  
**发现时间**: 2026-08-04 09:18  
**报告人**: PL  

## 问题描述

剧本游戏中左侧好感度显示刻度只有 0、20、40、60、80，没有 100。

## 预期行为

好感度刻度应该是：0、20、40、60、80、100（6 个刻度）。

## 实际行为

只显示 0、20、40、60、80（5 个刻度）。

## 可能原因

1. **FE 刻度配置问题**: 好感度显示组件的刻度数组只配置了 5 个值
2. **最大值问题**: 好感度最大值被设置为 80 而非 100
3. **显示逻辑问题**: 刻度计算时使用了错误的最大值

## 排查方向

### FE 排查
- 文件: `frontend/src/components/AffectionDisplay.vue` 或 `frontend/src/views/GameView.vue`
- 检查好感度刻度数组的定义
- 检查好感度最大值的配置
- 检查刻度渲染逻辑

### BE 验证
- 文件: `backend/app/services/narrative/affection_service.py`
- 确认好感度最大值是 100（`MAX_AFFECTION = 100`）

## 修复方案

修改 FE 好感度刻度配置，确保包含 100：
```javascript
// 修复前
const affectionLevels = [0, 20, 40, 60, 80];

// 修复后
const affectionLevels = [0, 20, 40, 60, 80, 100];
```
