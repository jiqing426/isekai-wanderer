# CR-017 解锁动效系统 — 需求分析

## 需求概述
新增全局解锁弹窗组件 UnlockModal，用于展示 CG/成就/隐藏剧情/角色语音/限定剧本等解锁动画。

## 触发场景
1. 解锁 CG
2. 解锁成就
3. 解锁隐藏剧情
4. 解锁角色语音
5. 解锁限定剧本
6. 完成重要任务奖励

## 组件类型
- CG 解锁卡片
- 成就解锁卡片
- 奖励飘字提示
- 多奖励汇总弹窗

## 技术要点

### 前端
- 新增全局组件 UnlockModal.vue
- 支持多种解锁类型
- 动效规范：背景变暗200ms、卡片弹入400ms、图标500ms、文字600ms、按钮800ms
- 支持跳过、ESC关闭、点击遮罩关闭
- 移动端适配

### 后端
- 解锁记录存储（unlock_records 表）
- 解锁事件触发接口
- 解锁历史查询接口
