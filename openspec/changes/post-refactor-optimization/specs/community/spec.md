# Community Spec — CR-008 V2

## 需求概述

修复社区相关缺陷，优化帖子展示。

## 需求列表

### REQ-BUG-016: 帖子预览数增加（P1）

**场景 1**: 点击帖子增加预览数
- 用户点击帖子进入详情
- 后端 `view_count` 字段 +1
- 返回列表时显示更新后的预览数

**场景 2**: 并发访问
- 多个用户同时访问同一帖子
- 预览数正确累加
- 使用数据库原子操作 `UPDATE ... SET view_count = view_count + 1`

**场景 3**: 未登录访问
- 未登录用户访问帖子也增加预览数
- 基于 IP 或会话去重（可选）

**验收标准**:
- AC-016-1: 点击帖子后 `view_count` 字段 +1
- AC-016-2: 前端显示更新后的预览数
- AC-016-3: 并发访问时预览数正确累加

### REQ-FEAT-032: 帖子默认头像（P2）

**场景 1**: 用户有头像
- 帖子列表显示用户头像
- 头像来源：`author.avatar_url`

**场景 2**: 用户无头像
- 显示默认头像（系统提供）
- 默认头像样式统一（圆形，灰色背景）

**场景 3**: 头像加载失败
- 显示默认头像作为 fallback
- 不显示破损图片图标

**验收标准**:
- AC-032-1: 用户无头像时显示默认头像
- AC-032-2: 默认头像样式统一
- AC-032-3: 头像加载失败时显示默认头像

## 依赖

- BE: 需要确保帖子接口返回 `view_count` 字段
- BE: 需要实现预览数增加逻辑

## 风险

- 预览数高并发场景下的性能
- 需要考虑防刷机制
