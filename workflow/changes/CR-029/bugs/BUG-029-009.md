# BUG-029-009: 选择报错后按钮未重置

**优先级**: P1  
**发现时间**: 2026-08-04 09:31  
**报告人**: PL  

## 问题描述

剧本游戏中做出选择后如果报错（500），选择按钮没有重置，一直保持已点击的状态。

## 根因分析

**文件**: `frontend/src/views/GameView.vue` — `handleChoice()` 函数

```javascript
async function handleChoice(choiceId: string) {
  // ... 记录历史、触发任务进度 ...
  
  const result = await game.submitChoice(choiceId);
  
  // 如果发生错误，提前返回
  if (result?.error) {
    return;  // ❌ 直接返回，没有重置选择状态
  }
  // ...
}
```

当 API 返回错误时，函数直接 return，没有重置按钮的 loading/selected 状态。

## 修复方案

### FE 修复

在 `handleChoice()` 的 error 分支中添加状态重置：

```javascript
async function handleChoice(choiceId: string) {
  // ... 设置 loading 状态 ...
  
  try {
    const result = await game.submitChoice(choiceId);
    
    if (result?.error) {
      // 重置选择状态
      // TODO: 添加具体的重置逻辑
      return;
    }
    // ...
  } catch (err) {
    // 重置选择状态
    // TODO: 添加具体的重置逻辑
  }
}
```

需要 FE 确认具体的状态变量（如 `selectedChoiceId`、`isSubmitting` 等）并在 error/catch 中重置。
