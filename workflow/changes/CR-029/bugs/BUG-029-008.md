# BUG-029-008: 选择选项后报 500 错误

**优先级**: P0  
**发现时间**: 2026-08-04 09:31  
**报告人**: PL  

## 问题描述

剧本游戏中做出选择后，`POST /api/v1/game/{session_id}/choice` 接口返回 500 Internal Server Error。

## 根因分析

**错误堆栈**:
```
File "/app/app/services/narrative/memory_service.py", line 70, in extract_and_store
    if not mem_text or len(mem_text.strip()) < 5:
                           ^^^^^^^^^^^^^^
AttributeError: 'dict' object has no attribute 'strip'
```

**原因**: `gateway.py` 的 `extract_memory()` 方法期望返回 `list[str]`，但 LLM 有时返回 JSON 对象数组（如 `[{"fact": "..."}]`）而非字符串数组（`["..."]`）。当 `memory_service.py` 遍历结果时，`mem_text` 是 dict 而非 str，调用 `.strip()` 报错。

## 修复方案

### BE 修复

1. **`gateway.py` — 防御性解析**：确保 `extract_memory()` 返回的每个元素都是字符串
   ```python
   memories = json.loads(response.content)
   if isinstance(memories, list):
       # 提取字符串，跳过非字符串元素
       return [m if isinstance(m, str) else str(m.get('fact', m.get('text', ''))) for m in memories if m]
   return []
   ```

2. **`memory_service.py` — 防御性类型检查**：
   ```python
   for mem_text in memory_texts:
       if not isinstance(mem_text, str):
           mem_text = str(mem_text) if mem_text else ""
       if not mem_text or len(mem_text.strip()) < 5:
           continue
   ```
