# CR-023: 角色聊天流式对话功能

## 变更目标

实现角色聊天的流式对话功能，提供打字机效果的 NPC 回复体验。

## 影响范围

- 后端：新增 SSE 流式接口
- 前端：流式接收和打字机效果渲染
- 数据库：保存完整对话记录

## 成功标准

1. 用户发送文字后，显示 loading 状态
2. NPC 回复以流式方式返回，实现打字机效果
3. 完整对话记录保存到数据库
4. 错误处理和超时机制完善

## 功能清单
