# S017 每日任务系统

## REQ-008: 每日任务系统

### 需求概述

每日 3 个固定小任务，完成后获得 mock 碎片奖励。全部完成有额外奖励并延续 Streak 1 天。任务在 UTC 0:00 重置。

### Requirement: 每日任务列表

**ID**: REQ-008-R01  
**优先级**: P0  

系统每日生成 3 个固定任务：

| 任务 | 目标 | 奖励 |
| --- | --- | --- |
| 对话达人 | 与角色对话 5 次 | +10 碎片 |
| 选择大师 | 在剧情中做出 3 个选择 | +5 碎片 |
| 角色探索 | 查看 2 个不同角色的信息页 | +5 碎片 |

#### Scenario: 用户查看今日任务列表

- **Given** 用户已登录
- **When** 用户打开任务面板
- **Then** 展示 3 个任务及当前进度（如"对话达人 2/5"），未完成任务显示进度条，已完成任务显示勾选标记

#### Scenario: 任务在 UTC 0:00 自动重置

- **Given** 用户昨日已完成部分任务
- **When** UTC 0:00 后用户首次登录
- **Then** 所有任务进度归零，重新生成当日任务

### Requirement: 任务进度追踪

**ID**: REQ-008-R02  
**优先级**: P0  

系统实时追踪用户行为并更新任务进度。任务完成后自动发放碎片奖励。

#### Scenario: 对话任务进度更新

- **Given** 用户"对话达人"任务进度为 2/5
- **When** 用户与角色完成一次对话（一轮对话结束）
- **Then** 进度更新为 3/5

#### Scenario: 对话任务完成并发放奖励

- **Given** 用户"对话达人"任务进度为 4/5
- **When** 用户完成第 5 次对话
- **Then** 任务标记为已完成，发放 10 碎片，展示"任务完成 +10 碎片"toast 提示

### Requirement: 全完成奖励

**ID**: REQ-008-R03  
**优先级**: P0  

3 个任务全部完成时，额外发放 25 碎片奖励，并将 Streak 延续 1 天（即当日不断签，即使未登录也保持连续）。

#### Scenario: 全部任务完成触发额外奖励

- **Given** 用户已完成 2 个任务，第 3 个任务刚完成
- **When** 系统检测到 3/3 任务全部完成
- **Then** 发放额外 25 碎片，展示"全部完成！+25 碎片 + Streak 延续"弹窗

#### Scenario: Streak 延续机制

- **Given** 用户今日全部任务完成，streak 为 5
- **When** 用户明日未登录
- **Then** 后天登录时 streak 为 6（因全完成奖励延续了 1 天），而非重置为 1

### 不做范围（本 CR）

- 不做随机/个性化任务生成
- 不做任务难度分级
- 不做周任务/月任务
- 不做真实碎片消费

### R/C/U/D 完整性

| 动作 | 是否包含 | 说明 |
| --- | --- | --- |
| Create | 是 | 每日任务实例创建 |
| Read | 是 | 查询任务列表和进度 |
| Update | 是 | 进度更新、完成状态变更 |
| Delete | 否 | MVP 不删除任务记录，次日自动重置 |

### 下游约束

- 需要 DB 契约：每日任务实例表、进度记录、奖励发放记录
- 需要 API 契约：任务列表查询、进度更新（由行为事件触发）、奖励领取
- 需要与签到系统联动：全完成时触发 Streak 延续
- 验收需要真实后端验证：进度持久化、奖励发放、Streak 延续
- 验收需要浏览器交互：任务面板查看、进度实时更新
