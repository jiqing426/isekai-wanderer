# CR-021 REQUIREMENT阶段 - PM需求细化

## 需求概述

### 用户故事
作为一个游戏玩家，我希望能够与喜欢的角色进行对话聊天，以便更好地了解角色背景、增进好感度，并获得更好的游戏体验。

### 功能需求

#### FR-001: Header角色聊天Tab

- **优先级**: P0
- **验收标准**:
  - AC-001: Header显示"角色聊天"Tab，位于现有导航项之后
  - AC-002: 点击Tab跳转到角色聊天页面 `/character-chat`

### 非功能需求

#### NFR-001: 性能要求
- 页面加载时间 < 2秒
- 消息发送响应时间 < 1秒
- 好感度更新延迟 < 5秒

#### NFR-002: 兼容性要求
- 支持Chrome 90+、Firefox 88+、Safari 14+
- 移动端浏览器支持（iOS Safari 14+、Android Chrome 90+）

#### NFR-003: 可用性要求
- 界面响应式布局，适配PC和移动端
- 弹窗层级管理清晰，避免遮挡问题

### 数据需求

#### DR-001: 角色数据
- 复用现有API: `GET /api/v1/affection`
- 返回字段: character_id, character_name, avatar_url, affection_level, affection_value

#### DR-002: 聊天消息
- 新增API: `GET /api/v1/character-chat/{character_id}/messages`
- 返回字段: message_id, sender_type (npc/user), content, created_at
- 分页参数: page, page_size

#### DR-003: 发送消息
- 新增API: `POST /api/v1/character-chat/{character_id}/messages`
- 请求字段: content
- 返回字段: message_id, created_at

#### DR-004: 推荐话题
- 新增API: `GET /api/v1/character-chat/{character_id}/topics`
- 返回字段: topic_id, topic_text

#### DR-005: 送礼功能
- 复用现有API: `POST /api/v1/gifts/send`
- 复用现有API: `GET /api/v1/gifts/history`
