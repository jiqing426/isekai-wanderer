## 1. 产品概述

### 1.1 一句话定义

**AI 驱动的互动视觉小说平台** — 每一次选择，都改变世界。

### 1.2 产品定位

面向二次元 / 视觉小说 / 互动叙事爱好者，提供由 AI 实时生成的分支剧情体验。用户穿越到异世界，与 AI 角色建立羁绊，通过选择推动剧情走向不同结局。

### 1.3 核心卖点

| 卖点 | 说明 |
|------|------|
| 🤖 AI 驱动叙事 | 每个故事由 AI 独特生成，实时适应玩家选择 |
| 🔀 分支路径 | 玩家决定创造有意义的分支，多种结局和后果 |
| 💕 角色羁绊 | 与 AI 角色建立深度关系，角色会记住玩家并一起成长 |
| 🖼️ CG 画廊 | 推进故事路线解锁精美 CG 插图 |
| 🧠 记忆回溯 | AI 跨会话记忆影响剧情走向，可可视化查看 |
| 🌐 创作社区 | 分享独特故事，阅读他人作品（UGC） |

### 1.4 数据指标（展示用）

- 50,000+ 故事已创建
- 4.9★ 平均评分
- ProductHunt #3

## 3. 核心功能模块

### 3.1 AI 叙事引擎（W06 Gameplay）

**核心体验：** 视觉小说式阅读 + AI 实时生成 + 玩家选择驱动分支

- **叙事模式：** 小说文本逐句展示，配合背景图/BGM，沉浸式阅读
- **AI 对话：** 角色与玩家实时对话，AI 根据角色性格 + 剧情上下文生成回复
- **选项分支：** 关键节点提供 2-4 个选项，选择影响剧情走向、角色好感度
- **回溯功能：** 回到任意选择点重新体验不同分支（付费功能）
- **角色语音：** 日/英双语 AI 语音合成（付费功能）

**示例场景（樱色记忆 · 雪乃路线）：**
> 樱花花瓣在温暖的春风中悠然飘落，你沿着河畔小径缓步前行。雪乃走在你身旁……  
> 「我想告诉你一件事。一件我从未告诉过任何人的事。」

### 3.2 角色系统（W09 Character）

- **好感度系统：** 0-100 分，通过选择互动提升/降低
- **信任等级：** Lv.1 → Lv.5，影响可解锁的剧情深度
- **性格雷达图：** 温柔 / 智慧 / 勇敢 / 神秘 / 忠诚 五维
- **羁绊时间线：** 记录玩家与角色的每个关键事件
- **角色详情卡：** 年龄、身高、生日、喜好等基础信息
- **好感度挽回：** 当好感度下降时，系统提示恢复路径

### 3.3 碎片经济系统（W07 Dashboard）

**碎片（✨）是平台内通用货币：**

| 获取方式 | 数量 |
|----------|------|
| 每日任务完成 | +25 ✨ |
| 连续签到 | +15 ✨/天 |
| 成就解锁 | +50 ✨ |
| 充值购买 | 100/500/1200 ✨ |

| 消耗方式 | 花费 |
|----------|------|
| 头像框 | 80 ✨ |
| 额外存档位 | 150 ✨ |
| 语音试用 | 50 ✨ |
| 回溯 x3 | 200 ✨ |

### 3.4 成就系统（W07 Dashboard）

- **稀有度分级：** 普通 / 稀有 / 史诗 / 传说
- **示例成就：**
  - 🌸 初次绽放（普通）— 完成第一次剧情
  - 💕 真心话（稀有）— 触发角色深层对话
  - 🔄 时间循环（稀有）— 使用回溯功能
  - 🏆 路线大师（史诗）— 完成所有分支
  - 🔒 真爱（传说）— 达成最高好感度
- **总计 32 个成就**

### 3.5 签到系统（W07 Dashboard）

- 7 天循环签到，连续签到额外奖励
- 可视化日历：✅ 已签到 / 🔥 今日 / ○ 未签到

### 3.6 社区系统（W12 Community）

- 玩家帖子：心得分享、攻略、结局讨论
- 互动：❤️ 点赞 / 💬 评论 / 🔄 分享
- 防剧透标记
- 按剧本分类浏览

## 8. 技术要点（推断）

| 领域 | 技术方向 |
|------|---------|
| AI 叙事 | LLM 上下文窗口管理 + 角色 Persona Prompt + 分支树结构 |

| 支付 | Stripe 集成，Apple/Google Pay |
| 社区 | 帖子 CRUD + 防剧透 + 评论系统 |

## 10. 风险 & 待确认项

| 项目 | 说明 |
|------|------|
| AI 内容审核 | AI 生成内容需过滤 NSFW / 违规内容 |
| 多语言支持 | 当前中/英/日，需确认其他语种计划 |
| 碎片经济平衡 | 免费用户碎片获取 vs 消耗是否平衡 |
| UGC 审核 | 用户创作剧本的内容审核机制 |
| 未成年人保护 | 页面 W16-teen 青少年模式（出现在 KinSoul 项目，本产品暂无） |
| 付费转化率 | 免费版 3 次/天的限制是否足以驱动转化 |
