## 任务分类

### 🔴 P0 - 高优先级（核心功能）

#### BE 任务
1. **自由对话接口 500 错误**
   - `/api/v1/game/{sessionId}/free-chat` - 500
   - `/api/v1/game/{sessionId}/free-chat/topics` - 500
   - `/api/v1/game/{sessionId}/free-chat/history` - 500
   - 根因：后端接口实现问题

2. **送礼记录接口 404**
   - `/api/v1/game/{sessionId}/gift-history` - 404
   - 需要实现送礼记录查询接口

3. **剧本大厅接口优化**
   - 新增 `hot_value` 字段到剧本表
   - 实现分类筛选、排序切换、分页加载
   - SQL 排序规则：`ORDER BY score DESC, script_id ASC` 或 `ORDER BY hot_value DESC, script_id ASC`

4. **签到逻辑实现**
   - 签到获取碎片规则
   - 连续签到奖励递增
   - 签到日期记录

5. **游戏统计数据记录**
   - 游戏时长、对话次数、选择次数等统计
   - 数据库表设计
   - 记录 API 实现

#### FE 任务
1. **登录/注册页面 - 密码显示/隐藏**

2. **剧本大厅页面 - 分类筛选和排序**
   - 添加分类 Tab 栏
   - 添加排序下拉选择器（评分优先/热门优先）
   - 实现滚动分页加载
   - 修复同分剧本乱序问题

3. **游戏内容页面优化**
   - 进度条数据展示
   - 左侧栏显示角色名称和好感度
   - 隐藏设置按钮
   - 添加送礼功能入口

4. **个人中心优化**
   - 签到按钮功能实现
   - 已签到日期高亮
   - AI 记忆添加说明提示
   - 游戏统计数据展示
   - 快速继续游玩模块开发

5. **移动端优化**
   - 删除底部导航栏
   - 游戏页面 100vh 滚动问题修复

6. **自由对话页面**
   - 高度调整：`height: calc(100vh - 72px)`
   - 修复接口错误

7. **Header 优化**
   - 个人中心跳转修复（/personal-center）
   - 头像显示逻辑
   - 登录状态校验

8. **设置页面优化**
   - 头像上传大小限制 5MB
   - 播放偏好滑动进度条保存逻辑
   - 个人资料布局调整

9. **收藏馆优化**
