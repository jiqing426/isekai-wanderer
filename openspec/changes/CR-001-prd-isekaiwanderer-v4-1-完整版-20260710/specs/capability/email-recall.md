# 邮件召回（P1）

**MAS（最小可用标准）**：7 天未登录自动发邮件，不做个性化召回。

## Capability: 邮件召回

### Requirement: 未登录自动召回邮件

系统每日检查用户最后登录时间，对 7 天未登录的用户自动发送召回邮件。

#### Scenario: 7 天未登录触发召回

**Given** 用户上次登录时间为 7 天前
**When** 系统每日定时任务执行
**Then** 系统向该用户发送召回邮件（含游戏名称和"回来看看"引导链接）
**And** 标记该用户本次召回已发送，避免重复发送

#### Scenario: 活跃用户不触发召回

**Given** 用户 3 天前登录过
**When** 系统每日定时任务执行
**Then** 不向该用户发送召回邮件
