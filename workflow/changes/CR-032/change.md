# CR-032: 游戏交互与数据持久化修复

## 变更目标
修复用户反馈的5个游戏交互和数据问题，提升用户体验和数据准确性。

## 问题清单

### BUG-032-001: 个人中心继续游戏角色错误
**现象**：从个人中心点击"继续游戏"跳转后，角色不是当前存档的角色
**根因**：跳转链接 `/game?session=${session_id}` 没有携带 `character_id` 参数
**影响**：P1 - 核心游戏体验
**责任角色**：FE

### BUG-032-002: 剧本游戏左侧头像显示异常
**现象**：新角色没有头像时，显示的是图片占位符而不是角色名首字母
**期望**：无头像时显示默认头像（角色名称首字母）
**影响**：P2 - UI 一致性
**责任角色**：FE

### BUG-032-003: 自由对话角色错误
**现象**：剧本游戏中点击"自由对话"跳转后，对话对象是主角而非当前NPC角色
**根因**：`goToFreeChat()` 传递的 `characterId` 是 `game.currentDialogue?.character_id`（NPC），但路由可能未正确使用
**影响**：P1 - 核心交互逻辑
**责任角色**：FE

### BUG-032-004: 碎片兑换对话次数被错误重置
**现象**：每天8点重置时，用碎片兑换的额外对话次数也被清零
**期望**：只重置每日免费对话次数（base_quota），碎片兑换的额外次数（fragment_extra）不应重置
**根因**：`reset_all_daily_quotas()` 逻辑错误，将 fragment_extra 也清零
**影响**：P0 - 付费功能异常
**责任角色**：BE

### BUG-032-005: 赠送礼物弹框信息缺失
**现象**：
1. 赠送成功后弹框中没有显示当前好感度、剩余碎片、好感度变化
2. 角色详情页的"送礼记录"点击时查询所有角色的记录，而非当前角色
3. 送礼记录在游戏页面加载时就查询，而非点击时才查询
**期望**：
1. 弹框显示完整信息：当前好感度、剩余碎片、好感度变化
2. 送礼记录按需查询，只查询当前角色
3. 点击"送礼记录"按钮时才发起查询
**影响**：P2 - 交互体验
**责任角色**：FE

## 影响范围
- 前端：PersonalCenterView、GameView、GiftModal、FreeChatView
- 后端：quota_service.py（每日重置逻辑）
- 数据：DialogueQuota 表的 fragment_extra 字段处理

## 成功标准
1. 继续游戏跳转后角色正确
2. 无头像角色显示首字母占位符
3. 自由对话对象是当前NPC
4. 碎片兑换的对话次数在每日重置后保留
5. 送礼弹框显示完整信息，送礼记录按需查询

## 风险
- 低：主要是前端逻辑修复和后端一处重置逻辑调整
- 需验证：每日重置逻辑修改后不影响正常用户的免费额度重置
