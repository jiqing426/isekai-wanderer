# Proposal: CR-001 — Isekai Wanderer MVP (v2)

## Why

- 构建"异世界漫游（Isekai Wanderer）"MVP——一款 AI 驱动的二次元交互式叙事网页游戏
- 通过结构化剧本 + 跨会话角色记忆 + 好感度养成的核心循环，验证产品市场契合度（PMF）
- MVP 聚焦核心游戏循环、留存机制、商业变现验证和完整用户体验
- 核心痛点数据支撑：人设崩塌（85%用户遭遇）、缺乏长期目标（70%）、角色失忆（65%）、网页端体验差（40%）、缺乏回访动力（60%）

## What Changes

### P0 核心功能（11 个模块）

- **S001 叙事一致性引擎**：剧情节点 + 状态机 + 角色性格约束三层防护；关键节点人工预设，AI 仅填充节点间过渡对话
- **S002 结构化剧本系统**：MVP 交付 3 个剧本——乙女恋爱（3 条路线 × 2-3 结局，主力）、奇幻冒险（2 条路线 × 2 结局，轻量）、悬疑推理（2 条路线 × 2 结局，轻量）（已确认，见 Q-001）
- **S003 跨会话角色记忆**：向量数据库存储；高置信度（>0.8）才召回；不确定时不提及
- **S004 好感度系统（基础版）**：5 等级（相识→暧昧→信赖→羁绊→挚爱）；0-100 数值化；每次互动变化 ≤±5；半隐藏进度条
- **S005 首玩保障**：新用户首次进入自动触发引导对话；首次对话失败率 <5%；首玩完成率追踪
- **S006 基础视觉呈现**：每角色 ≥5 种表情立绘；每剧本 ≥3 场景背景 + 2 首 BGM；流式文字动画 ≥30fps；首屏加载 <3s
- **S007 用户账户系统**：邮箱注册/登录（含验证）+ OAuth mock 模板（Google/Discord，架构预留真实接口）；注册后 3 步引导
- **S016 每日签到 Streak**：每日自动签到（UTC 0:00）；连续天数追踪；Day 3/7/14/30 阶梯奖励（mock 碎片）
- **S017 每日任务系统**：每天 3 个固定任务（对话达人/选择大师/角色探索）；全完成额外奖励 mock 碎片
- **S024 内购系统（mock）**：mock 内购模板（单剧本购买 + 碎片充值）；架构预留 Apple/Google/Stripe 真实支付接口；验证付费意愿
- **S025 订阅方案体系（mock）**：mock 订阅模板（Free/Basic/Standard/Premium 四档 + 月付/年付 + USD/JPY/EUR/KRW 四货币）；架构预留真实订阅接口；验证订阅转化

### P1 扩展功能（12 个模块，含 MAS 定义）

每个 P1 模块必须定义最小可用标准（MAS），避免过度投入：

- **S008 情感节奏控制**：MAS = 关键节点情绪标注 + 基础节奏曲线，不做 AI 自适应
- **S009 AI 风格化对话**：MAS = 3 种预设风格（温柔/傲娇/冷静），不做动态风格切换
- **S010 社交分享**：MAS = 结局分享按钮（生成链接），不做社交平台集成
- **S011 UGC（用户生成内容）**：MAS = 自定义角色名称 + 简单外观选择，不做自由创作
- **S012 国际化**：MAS = 英文 UI 翻译，不做多语言切换
- **S013 CG 画廊**：MAS = 解锁 CG 列表展示，不做收藏/分享功能
- **S014 SEO**：MAS = 基础 meta 标签 + sitemap，不做高级 SEO 优化
- **S015 Discord 集成**：MAS = 官方 Discord 链接 + 简单 Bot 通知，不做深度集成
- **自由对话**：MAS = 预设话题选择（5 个），不做真正自由对话
- **邮件召回**：MAS = 7 天未登录自动发邮件，不做个性化召回
- **Push 通知**：MAS = PWA 通知权限提示，不做主动推送
- **结局分享**：MAS = 结局卡片生成（图片+文字），不做社交分享

### MVP 排除

| 能力 | 排除原因 |
| --- | --- |
| Admin 管理后台 | CEO 明确排除，后续 CR 补齐 |
| 真实支付/OAuth | MVP 使用 mock 模板，架构预留真实接口，用户后续替换凭证 |

## Non-Goals

- 不接入任何真实支付（Apple/Google/Stripe）
- 不接入真实 OAuth（Google/Discord API）
- 不做深度 UGC（自由创作/自定义剧本）
- 不做社交平台深度集成（仅分享链接）
- 不做真正自由对话（仅预设话题）
- 不做管理后台
- 不做多语言动态切换（仅英文 UI）

## Success Criteria

- D1 留存率 ≥40%（埋点统计）
- D7 留存率 ≥15%（埋点统计）
- 首玩完成率（完成首个剧本 1 条路线）≥30%（埋点统计）
- 签到 Streak Day3 到达率 ≥20%（系统数据）
- Mock 内购点击率 ≥5%（验证付费意愿）
- Mock 订阅点击率 ≥3%（验证订阅意愿）
- 停止条件：D1 <15% 或首玩完成率 <30%，暂停投入，复盘产品方向

## Impact

- 前端：PWA 网页端，全部新建（含 mock 支付/OAuth UI）
- 后端：API、叙事引擎、记忆系统、mock 支付/订阅逻辑，全部新建
- AI：LLM 集成、角色记忆、对话生成，全部新建
- 数据库：用户、剧本、记忆、好感度、签到、任务、mock 交易等表，全部新建
- 美术资源：角色立绘（3 剧本 × 3-5 角色 × 5 表情）、场景背景（3 剧本 × 3 场景）、BGM（3 剧本 × 2 首）、CG（3 剧本 × 3-5 张），全部新建
- 部署：全新部署
