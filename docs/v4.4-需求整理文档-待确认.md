## 四、双 Agent 架构

### 4.1 架构对比

| 对比项 | 📖 剧情 Agent | 💬 陪伴 Agent |
|--------|-------------|-------------|
| **触发方式** | 点击预设选项 / 到达集合点 | 自由输入框发送消息 |
| **是否推进剧情** | ✅ 是（推进 node、触发 choice） | ❌ 否（纯聊天） |
| **是否改好感度** | ✅ 是 | ❌ 否 |
| **是否触发集合点** | ✅ 是 | ❌ 否 |
| **是否剧透** | 按剧本走 | ❌ 禁止剧透未玩内容 |
| **记忆来源标记** | `source: "game_event"` | `source: "free_chat"` |
| **主模型** | qwen3.7-max | deepseek-v4-flash |
| **API 端点** | `/api/v1/game/dialogue` | `/api/v1/chat/free` |

### 4.2 陪伴 Agent 红线规则

**✅ 可以做的**：
- 讨论已经发生过的剧情
- 聊角色的兴趣爱好、日常、心情
- 聊世界观、背景设定
- 对用户表达情感、闲聊陪伴
- 回忆之前聊过的事（读记忆）

**❌ 不可以做的**：
- 透露玩家尚未体验的剧情
- 生成影响主线的"关键记忆"
- 改变好感度、游戏状态
- 主动提供选择选项
- 推进到下一个 node

**被问到未玩剧情时的统一回复**：
> 「这个嘛……你自己去经历不是更有意思吗？」  
> 「嗯……我好像有点记不清了，也许我们还需要多相处一段时间？」

## 七、好感度系统

### 7.1 核心规则

| 规则 | 说明 |
|------|------|
| 范围 | 0-100（超出边界会钳制） |
| 单次变化上限 | ±5（防止暴涨暴跌） |
| 触发方式 | **仅选项触发**，自由对话不改好感度 |
| 用户隔离 | 按 user_id + character_id 独立存储 |
| 结局判定 | ≥60 好结局 / <60 坏结局 |

### 7.2 好感度等级（5 级）

| 等级 | 数值范围 | 中文标签 | 角色行为变化 |

| Lv.3 信赖 | 40-59 | 信赖 | 主动关心，分享心事，可以开玩笑 |
| Lv.4 羁绊 | 60-79 | 羁绊 | 撒娇/吐槽，展现脆弱面，主动找话题 |
| Lv.5 挚爱 | 80-100 | 挚爱 | 深情表达，独占欲，偶尔害羞 |

### 7.3 手动存档 + 送礼 + 退出提醒

## 八、用户隔离

### 8.1 隔离原则

**每个用户 100% 独立**：
```
用户 A ──→ 查 character_memories WHERE user_id = A  ──→ A 的记忆
用户 B ──→ 查 character_memories WHERE user_id = B  ──→ B 的记忆
互不可见，互不影响
```

### 8.2 数据层隔离

**已有表（天然支持 user_id 隔离）**：
- `character_memories` — 角色记忆，按 user_id + character_id 隔离
- `game_sessions` — 游戏会话，按 user_id 隔离
- `affections` — 好感度，按 user_id + character_id 隔离
- `free_chat_sessions` — 自由对话会话，按 user_id 隔离

**新增表**：
- `user_personas` — 用户画像
- `convergence_points` — 剧情集合点
- `affection_history` — 好感度变化历史

### 8.3 记忆隔离标记

```python
# 剧情产生的记忆 → 剧情 Agent 可读，陪伴 Agent 也可读（已发生的）
source = "game_event"

# 自由对话产生的记忆 → 只有陪伴 Agent 读，剧情 Agent 不读
source = "free_chat"
importance = 0.3  # 权重低于剧情记忆
```
