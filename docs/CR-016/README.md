# CR-016 订阅付费体系 + 动态对话额度

## 功能范围

本 CR 实现完整的订阅付费体系，包含 4 档订阅（Free / Basic / Standard / Premium）、动态梯度对话额度、Paywall 触发引擎和付费引导 UI 组件。

## 核心模块

| 模块 | 说明 | 优先级 |
|------|------|--------|
| M1: 订阅档位 & 权限模型 | 4 档定价 + 权限矩阵 | P0 |
| M2: 动态梯度对话额度 | 基于用户生命周期的额度计算（蜜月/养成/常规/回归） | P0 |
| M3: Paywall 触发引擎 | T1-T8 触发场景 + 限流控制 | P0 |
| M4: 付费引导组件 | 全屏弹窗 / Banner / Toast / 角标 | P1 |
| M5: 全局限流计数 | 每日弹窗上限 + 蜜月期保护 | P0 |
| M6: 碎片购买联动 | 碎片可购买额外对话次数 | P1 |
| M7: 订阅管理 | 购买/续费/降级/支付 Webhook | P0 |

## 配置文件

- `subscription_config.json` — 订阅档位权限矩阵、动态额度规则、Paywall 规则、消耗规则
- `paywall_copy.json` — T1-T8 各场景付费引导文案模板

## 订阅档位速览

| 档位 | 价格 | 对话额度 | 存档 | 剧本 | 语音 | 回溯 | UGC | 碎片折扣 |
|------|------|----------|------|------|------|------|-----|----------|
| Free | $0 | 动态梯度(3-10) | 1 | 试用 | ✗ | ✗ | ✗ | — |
| Basic | $1.99 | 30/天 | 5 | 全部普通 | ✗ | ✗ | ✗ | — |
| Standard | $4.99 | 无限 | 无限 | 全部普通 | ✓ | ✓ | ✗ | — |

## 动态额度规则（Free 档）

- 蜜月期（注册 1-3 天）：10 次/天
- 养成期（注册 4-7 天）：5 次/天
- 常规期（注册 8 天+）：3 次/天
- 回归用户（≥7 天未登录）：回归起 3 天 5 次/天
- UTC 00:00 统一重置
