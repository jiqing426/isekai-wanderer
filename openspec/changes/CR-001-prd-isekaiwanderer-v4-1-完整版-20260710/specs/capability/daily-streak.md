# S016 每日签到 Streak 系统

## REQ-007: 每日签到 Streak 系统

### 需求概述

每日自动签到机制，追踪连续登录天数并提供阶梯奖励。MVP 使用 mock 碎片作为奖励货币（不接入真实支付）。

### Requirement: 每日自动签到

**ID**: REQ-007-R01  
**优先级**: P0  

系统每日 UTC 0:00 自动为用户执行签到。签到状态按用户独立追踪。

#### Scenario: 用户当日首次登录触发签到

- **Given** 用户今日尚未签到
- **When** 用户在 UTC 0:00 后首次登录
- **Then** 系统自动记录今日签到，streak 天数 +1，展示签到成功提示和当前连续天数

#### Scenario: 用户当日重复登录不重复签到

- **Given** 用户今日已签到
- **When** 用户再次登录
- **Then** 不重复记录签到，streak 天数不变

#### Scenario: 跨日登录保持连续

- **Given** 用户昨日已签到，今日登录后签到
- **When** 今日签到完成
- **Then** streak 天数从 N 变为 N+1

### Requirement: 断签处理

**ID**: REQ-007-R02  
**优先级**: P0  

用户某日未登录签到时，streak 中断，次日重新从 1 开始计算。

#### Scenario: 用户断签后重新签到

- **Given** 用户昨日未签到，前日 streak 为 5
- **When** 用户今日登录并签到
- **Then** streak 重置为 1，展示"连续中断，重新开始"提示

### Requirement: 阶梯奖励

**ID**: REQ-007-R03  
**优先级**: P0  

连续签到达到特定天数时发放阶梯奖励（mock 碎片 + 特殊内容）：

| 天数 | 奖励 |
| --- | --- |
| Day 3 | 50 碎片 + 隐藏对话片段 |
| Day 7 | 100 碎片 + 稀有 CG |
| Day 14 | 200 碎片 + 独占 CG |
| Day 30 | 500 碎片 + 独占 CG |

#### Scenario: 用户达到 Day 3 奖励

- **Given** 用户 streak 从 2 变为 3
- **When** 签到完成
- **Then** 系统发放 50 碎片，解锁隐藏对话片段，展示奖励弹窗

#### Scenario: 用户达到 Day 7 奖励

- **Given** 用户 streak 从 6 变为 7
- **When** 签到完成
- **Then** 系统发放 100 碎片，解锁稀有 CG，展示奖励弹窗

### Requirement: 签到日历展示

**ID**: REQ-007-R04  
**优先级**: P0  

用户可查看签到日历，显示当月签到记录和 streak 天数。

#### Scenario: 用户查看签到日历

- **Given** 用户已登录
- **When** 用户进入签到页面
- **Then** 展示当月日历，已签到日期标记，当前 streak 天数，下一阶梯奖励进度

### 不做范围（本 CR）

- 不做补签卡功能
- 不做签到分享社交功能
- 不做真实碎片充值/消费（mock 碎片仅展示累积）

### R/C/U/D 完整性

| 动作 | 是否包含 | 说明 |
| --- | --- | --- |
| Create | 是 | 每日签到记录创建 |
| Read | 是 | 查询签到状态和 streak 天数 |
| Update | 是 | streak 天数更新（断签重置） |
| Delete | 否 | MVP 不删除签到记录 |

### 下游约束

- 需要 DB 契约：签到记录表、streak 状态表、奖励发放记录
- 需要 API 契约：签到状态查询、手动签到（兜底）、奖励领取
- 需要定时任务：UTC 0:00 自动签到（或登录时触发）
- 验收需要真实后端验证：签到持久化、streak 计算、奖励发放
- 验收需要浏览器交互：签到日历查看、奖励弹窗
