# S011 UGC 用户生成内容（P1）

**MAS（最小可用标准）**：自定义角色名称 + 简单外观选择（3 种预设），不做自由创作。

## Capability: UGC

### Requirement: 自定义角色名称

玩家可为自己的角色设置自定义名称，游戏中角色对话使用该名称显示。

#### Scenario: 玩家设置角色名称

**Given** 玩家在游戏中进入角色设置页面
**When** 玩家输入自定义名称（1-12 字符，无违规词）并保存
**Then** 游戏中所有对话和界面中该角色显示为自定义名称

#### Scenario: 名称违规拦截

**Given** 玩家输入包含违规词的名称
**When** 玩家点击保存
**Then** 系统提示"名称包含不当词汇，请修改"

### Requirement: 简单外观选择

玩家可从 3 种预设外观中选择角色形象（发型/服装组合）。

#### Scenario: 玩家选择预设外观

**Given** 玩家在角色设置页面
**When** 玩家从 3 种预设外观中选择一种
**Then** 游戏中角色立绘切换为所选外观
